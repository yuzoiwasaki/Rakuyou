## 初手からの確認

局面指定10局は既存4勝1敗、候補3勝1敗1未決着。候補の新規定跡命中は3局で、両追加手が入った2局は勝ち、△7二金だけ入った1局は同一局面を反復して手数上限となった。ユーザーは組み上がりを了承。

```sh
caffeinate -i python3 experiments/white-silver63-gold72/run_startpos.py
```

結果は `results/white-silver63-gold72-startpos20.json`。初手から既存10局・候補10局、すべて先手が通常版、後手が新米長玉。通常側は標準定跡ON・20手まで、後手は専用定跡44手まで。深さ15・秒読み10秒・1thread・Hash512MB・総手数256手。両群で変更前の同じエンジン・評価データを使い、標準定跡も出力別にコピーして固定する。

標準定跡はエンジン既定のランダム選択。同じ番号の両群に同じ序盤を保証する比較ではない。新しい定跡への命中数・組み上がり・明確な問題を確認する。未命中局や過去バッチを混ぜて効果を断定しない。手数上限は未決着で、千日手の自動裁定は行わない。終了後に反復局面も確認する。中断時は同じコマンドで保存手順から再開できるが、探索履歴はリセットされる。
