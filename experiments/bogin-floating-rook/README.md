# 棒銀に対する浮き飛車・3九玉の試験

早い▲4六歩・▲3六歩を省き、浮き飛車の横利きを残す。
玉は▲3八銀・▲4九金に支えられた▲3九玉型を目指す。
▲7八金は左側に残し、登録手順では▲2八玉へ進めない。

## 条件を限定した二つの手順

第11局の14手目△7二銀までを共通の入口にする。

- 交換を許された場合：▲2六歩 △8三銀 ▲2五歩 △8四銀 ▲2四歩
  △同歩 ▲同飛 △8五銀 ▲2六飛 △3二金 ▲3八銀 △4一玉 ▲3九玉。
- △3三角の場合：▲2六歩 △8三銀 ▲2五歩 △3三角 ▲2六飛
  △7四銀 ▲3六飛 △2二銀 ▲3八銀 △6五銀 ▲3九玉。

交換側には△3二金と△8五銀の手順前後も収録する。
これらの相手の応手は適用条件であり、実戦で必ず出現するわけではない。
未登録局面は通常探索に戻す。探索中の玉移動を禁止する実装はしていないため、
定跡を離れた後の▲2八玉や飛車の使い方は対局で確認する。

## 作成・検証

```sh
python3 experiments/bogin-floating-rook/prepare.py
```

正式版42局面を基に、12局面を追加・置換して試験版53局面を生成する。
置換するのは既存の `bogin-silver83-move17-ply17-4i5h` だけ
（▲5八金を▲2五歩に変更）。後手の定跡や他の既存登録は維持する。
保留中の角転換案は混ぜない。

生成先は `results/bogin-floating-rook/` の `baseline-book.txt` と
`candidate-book.txt`。両側ともBookMaxPly32で使用する。
正式book・bin内のbook・C++・既定値は変更しない。
全登録手の合法性と命中、手順前後での合流、早い△8六歩への探索復帰、
OwnBook OFFでの抑止をネイティブエンジンで確認する。

## 現時点の判断材料

先手視点、各局面で候補を限定した短時間比較。

| 局面 | 比較 | 深さ |
| --- | --- | --- |
| 交換後、△3二金 | ▲3八銀−28／▲1六歩−94 | 22 |
| 続いて△4一玉 | ▲3九玉+63／▲1六歩−38 | 21 |
| 交換なし、▲3六飛・▲3八銀に△6五銀 | ▲3九玉−206／▲7五歩−258 | 23 |
| 交換なし、飛車がまだ2六・△3二銀 | ▲3六飛−108／▲3九玉−282 | 23 |

最後の比較から、玉を囲うだけのために飛車の活動を遅らせない。
別局面の数値同士は直接比較しない。強さの向上や採用判断には使わず、
形の確認と今後の対局検証の候補とする。
入力と生の探索結果は同名resultsディレクトリの `king39*.json`。

## 短い試走

深さ15・相手の応手を固定しない16手分の試走では、14手目からだと相手は
△6四歩で棒銀を選ばず、定跡から外れた。△8三銀までの16手目からだと
▲2五歩〜▲2六飛〜▲3六飛は定跡で実現したが、22△6五銀で分岐した。
この局面の23▲3八銀は−304、▲3四飛は−153（深さ23）。玉を収めるために
この差を強制することはせず、未登録にした。▲3九玉型まで自然な対局で
到達する頻度と、その後の玉移動は未検証。両本線は条件付きの形の提示である。
