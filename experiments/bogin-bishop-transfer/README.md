## 浮き飛車の初期確認

共通の14手目△7二銀から▲2六歩 △8三銀 ▲2五歩。
相手が△8四銀と進める場合は▲2四歩 △同歩 ▲同飛 △8五銀 ▲2六飛。
最後の▲2六飛は+2（深さ23、先手視点）。同局面を通常側の設定で
読み直した後手評価も−27（深さ22）で、条件付きの例としてはほぼ互角。

ただし相手は18△3三角で交換を止められる。ここでの▲2六飛は−195、
▲3八銀は−124（同条件、深さ22）。▲2六飛から▲3六飛と横へ使う予測手順がある。
交換を許される前提で定跡を固定せず、この分岐を次に検討する。

交換後の▲2六飛に△8六歩打とされた場合、▲同歩が+296（深さ23）。
銀交換・角交換から2筋で反撃する予測手順で、浮き飛車が横だけでなく
2筋にも圧力を残す点を確認した。いずれも短時間の局面診断であり対局結果ではない。
局面入力・探索結果・合法性確認済みの比較図は `results/bogin-floating-rook/`。
浮き飛車案はまだ試験定跡へ追加していない。

## 保留した角転換案

第11局の30手目局面から、▲5九飛に代えて▲4五歩を先に指す案。
相手が登録した応手を選んだ場合に、▲3六歩・▲3七桂を整えて
▲7九角～▲4六角へ転換する。飛車は5八に残す。

`entries.json` は31・33・35・37・39手目の6局面を追加する（33手目は手順前後の2局面）。
盤面・持駒・手番が一致したときだけ適用し、別の応手には通常探索で対応する。
正式定跡・評価関数・既定のBookMaxPlyは変更しない。

```sh
python3 experiments/bogin-bishop-transfer/prepare.py
```

`results/bogin-bishop-transfer/` に現行版と試験版の定跡、ハッシュ付きの
検証結果を生成する。全登録手の合法性・定跡命中、△8六歩打／△7六銀への
探索復帰、手数上限による抑止を確認する。
比較時は両方ともBookMaxPlyを40にする。現行版には32手を超える登録はない。

  この入口だけで明確な優位性があるとは言えない。
- 登録手順中の37▲7九角は+51、▲5九飛は−125（深さ23）。
  39▲4六角は−6、▲5九飛は−103（深さ23）。すべて先手視点。
- 33・35手目で早く角を引く案は低評価だった。準備手順を省略しない。
- これらは既知局面の限定候補比較。対局結果や一般的な棋力向上の証明ではない。
  相手がこの手順を選ぶ頻度、別の攻めへの対応、角転換後の反撃を今後確認する。
- 生の探索結果はローカルの同名resultsディレクトリに保存。
  長時間対局はまだ実施していない。大駒による攻めへの備えは別の検討課題。
