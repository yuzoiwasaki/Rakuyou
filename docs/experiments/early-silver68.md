# 先手3手目▲6八銀の小規模検証

この資料と `tools/experiments/early_silver68.py` は実験ブランチ用。mainへの採用は対局レビュー後に相談する。評価関数・正式定跡の変更や長時間対局はまだ実施していない。

## 仮説とここまでの検討

現行100局の第43局・第55局で、▲7六歩・▲3八銀・▲2六歩から早い▲3九玉・▲2七銀と進み、四間飛車側の4筋の歩交換と飛車進出を許した。ユーザーは不自然と判断した。

角道を開けず▲6八銀を先行し、四間飛車には▲5六歩～▲5七銀、居飛車には▲7八金・▲7七銀を軸に対応できないかを試す。浮き飛車なら▲3六歩を急がず横利きを残す。▲5八金～▲6七金で厚く構える案も許容する。一方の構想に固定せず、その場で自然に選べるかを見る。

短い限定候補解析では、3手目▲6八銀は居飛車への対応を含めると現行▲7六歩より低く評価された。▲7七銀まで組んだ検討局面では▲3八銀と▲5八金が深さ22で約−220の同水準。浮き飛車は手順次第で、▲3六歩後の▲2六飛には△1五角の問題がある。これらは探索の予測であり、改善の証明ではない。

ローカル資料（Git管理外）: `results/current-100-review/` の `early-silver-*.json`、`silver77-defense-analysis.json`、`gold67-analysis.json` と各HTML。元の100局は `results/current-book-match-depth15-100games-20261115-141538.json`。

## 条件

先手は新米長玉ON/support10/D10、後手は通常Rakuyou OFF/0/0。各ゲームで新規エンジン。初期局面から以下の4手を固定し、5手目以降は両側の定跡・探索に任せる。

| 条件 | 現行側 | 試作側 |
| --- | --- | --- |
| 四間飛車 | ▲4八玉△3四歩▲7六歩△4二飛 | ▲4八玉△3四歩▲6八銀△4二飛 |
| 居飛車・8筋 | ▲4八玉△3四歩▲7六歩△8四歩 | ▲4八玉△3四歩▲6八銀△8四歩 |
| 居飛車・銀 | ▲4八玉△3四歩▲7六歩△6二銀 | ▲4八玉△3四歩▲6八銀△6二銀 |

計6局。先手のみの検証で、先後交換ではない。深さ15固定、Threads1、Hash512MB/エンジン、BookMaxPly20、総256手上限、1手の通信待機上限300秒。秒読みではない。先手は正式統合定跡、後手は標準定跡。▲6八銀側に追加定跡を登録せず、未知局面は探索する。

以後の定跡命中も分岐によって異なるため、比較は開始手順とその後の定跡・探索を合わせたもの。相手の定跡選択はランダムで、乱数を揃えた比較ではない。各条件1局ずつの既知開発局面であり、勝率の優劣判定ではなく棋風・明確な欠点の確認が目的。途中の調整や過去バッチとの合算はしない。

全着手をエンジンの合法手一覧と照合し、盤面・持駒・手番が同じ局面をnative SFENで記録する。同一局面4回は連続王手の責任を判定しないため未解決扱いで止める。256手到達・未検証の入玉宣言も未解決。投了・合法手なしによる決着のみ勝敗集計する。未解決を引き分け0.5点にしない。

## 実行

Rakuyouディレクトリで実行する。`bin/match` は検証済み。ない場合は先に `make match -j2`。

```sh
caffeinate -i python3 tools/experiments/early_silver68.py \
  --output "results/early-silver68-sixgames-$(date +%Y%m%d-%H%M%S).json"
```

10手ごとに進捗表示し、毎手保存する。既存ファイルは上書きしない。中断はCtrl+Cで行い、表示された保存先を指定して続ける。

```sh
caffeinate -i python3 tools/experiments/early_silver68.py \
  --resume results/実際の保存先.json
```

再開は保存した手順の続きから、新規エンジン・空の探索ハッシュで行い、その事実を記録する（連続実行と同じ手を保証しない）。バイナリ・評価データ・定跡・ランナー等のハッシュが変わった場合は再開を拒否する。エラー局は自動再試行しない。実行中にこれらのファイルを変更しない。同じ結果ファイルを複数プロセスで同時に実行しない。
