# 対局で分ける模倣学習：12／12元局面の選択と静的監査

2026年10月12日。[対局単位の設計案](2026-10-12-game-level-imitation-data-plan.md)に沿って、
プレマッチを学習用、電王戦を検証用として各12元局面を固定した。
全24件が静的監査を通過。欠損・除外・補充は0。教師比較・静止探索・学習更新はまだ0。
ユーザーの「深追いせず区切りたい」という希望を受け、次の転移確認も一回で終える案を記録した。

## 選択と監査結果

後手が指す直前、21手目以降の全候補を手数順に並べ、
`floor(i*(n-1)/11)`（i=0〜11）の添字で選んだ。
学習の候補32件、検証の候補46件。評価値・勝敗・駒の形・前回の改善度は使わない。

| 用途 | 棋譜 | 固定した手数（着手前） |
| --- | --- | --- |
| 学習 | 2011年12月21日・プレマッチ | 22、26、32、38、44、50、54、60、66、72、78、84 |
| 検証 | 2012年1月14日・電王戦 | 22、30、38、46、54、62、70、78、86、94、102、112 |

原本と変換済み入力のSHAを照合し、既存native probeで各元局面までの全着手履歴と実戦の次手を再生した。
全件で合法手、SFEN・Huffman同一性、反復履歴なしを確認。
選択規則、元棋譜の実戦手・履歴、保存したpendingレコードも読み直して再照合した。
学習／検証間の元局面の盤面・手番・持駒の重複は0。
新しい末端は生成していないので、その重複や適格性は未確認。

これは元局面の有効性の監査であり、学習用の対比較12組・検証用12組が確保されたという意味ではない。
実戦手と第一候補の一致、mate・境界値・反復、末端の条件によって対比較数は減り得る。
最後の手数を含むので、終盤の除外は想定する。除外後に局面を入れ替えない。

両局は後手敗局で、勝ち・drawはない。結果ラベルを保持し、勝敗損失は無効。
両方とも過去の学習・診断で使った棋譜なので、今回は前向きに勾配を対局で分ける転移診断であり、未見評価ではない。
現行評価から差分0で始める案を維持し、前回の20候補を継続学習しない。

## 再利用候補と実行範囲

同一の基準・履歴で無制限／実戦手限定の比較が保存されているのは、
プレマッチ22手目、電王戦22・62手目の3局面。
SHAが固定された以前のbaseline探索記録だけを再利用候補として記録した。
前回の学習候補の探索値を教師へ混ぜない。終了したrunnerやattempt markerの迂回も行わない。

再利用の完全照合が通れば、新しい通常探索は最大42回（残り21局面×2）、
通らなければ自動的に探索で置き換えず報告する。
固定末端は最大48回を上限案として維持するが、今回の段階では実行していない。
新しい教師・末端の有効件数と学習側のキー・勾配を報告してから、実学習を相談する。

深追いを避ける終了案は次のとおり。

- 準備時の欠損・除外は補充せず、その件数で実験可能か判断する。
- 実験する場合は、現行基準・差分0、KP／PP、1係数±0.01cp・局面全体10cp以内で、20更新を一度だけ。
- 検証側は学習キー・勾配・正則化選択へ使わない。結果を見た再調整、学習／検証の入替えをしない。
- 固定20平均候補で学習／電王戦への模倣方向と、既存35件の先後・drawへの影響を報告して終了する。
- 良い結果でも、通常探索の追加拡張・追加対局・データ拡張・採用へ自動的に進まない。

これは今後の区切り方の案で、今回許可された範囲は集合選択・静的監査まで。
今回のplanでは教師探索・学習・採用のフラグは全てfalse。
現在の評価・release・定跡・25cp補正と保存済み旧候補は維持した。
