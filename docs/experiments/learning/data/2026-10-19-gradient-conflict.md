# 学習方向の診断：混合では勝局・敗局の要求が衝突し、上限だけが原因ではない

## 結論

50/50混合では、勝局由来の局面と敗局由来の局面が共有係数を逆方向へ動かそうとする
強い傾向を確認した。上限が効かないゼロ開始時点でも、全体平均を下げる方向が敗局群を
悪化させる方向になっている。上限制約だけを原因とする説明は成り立たない。

一方、元局面群と追加局面群の方向は、全体としては逆向きではなかった。
局面追加そのものが常に旧局面と衝突している、とも言えない。
これは学習750局面だけでの局所的な診断であり、検証悪化の原因の確定や、
現在の特徴では両群を両立できないという証明ではない。

## 方法

探索専用と50/50混合、それぞれ差分ゼロと保存済み200更新後の計４状態を確認。
検証局面は集計にも方向決定にも使っていない。

各局面の1/(Gm)重みを全体で固定したまま、勾配を元／追加、勝／負へ分解した。
群ごとに重みを正規化し直すと実際の更新への寄与が変わるため、ここでは行わない。
各分解の和＋L2が実際の全体勾配に一致することも確認した。

方向の類似度はcosineで、＋１は同じ向き、０は直交、−１は正反対。
個々の係数ではなく全体ベクトルの値で、群内の局面差は隠れる。

| 状態 | 勝局群と敗局群 | 元局面群と追加局面群 |
| --- | ---: | ---: |
| 探索専用・ゼロ | +0.1008 | +0.2267 |
| 探索専用・200更新後 | −0.0900 | +0.0806 |
| 混合・ゼロ | −0.8213 | +0.2896 |
| 混合・200更新後 | −0.8361 | +0.2147 |

勝敗を混ぜると、勝った対局の局面を上げ、負けた対局の局面を下げる要求が強くなる。
今回、その要求が別々の係数で処理されず、かなり同じ係数を逆に動かそうとしている。
これは勝敗ラベルが間違いという意味ではない。勝敗が決まる前の局面をその最終結果で
教える難しさや、共通する特徴を使う難しさが候補となる。

## 上限を外した向きと、補正後の向き

保存状態で通常の正規化勾配による１ステップを仮計算し、
係数上限で切る前、切った後、局面上限で補正した後を比較した。
保存checkpointは更新せず、試算した係数を候補として保存・採用していない。
以下は勾配と方向の内積による一次近似。負は損失低下、正は損失増加を示す。
実際に繰り返し学習した結果を予測するものではない。

| 混合の状態・方向 | 勝局群の混合損失寄与 | 敗局群の混合損失寄与 |
| --- | ---: | ---: |
| ゼロ・上限補正前 | −0.00011827 | **+0.00002243** |
| 最終・上限補正前 | −0.00008584 | **+0.00001030** |
| 最終・係数上限後 | −0.00004877 | **+0.00000267** |
| 最終・局面上限補正後 | −0.00001703 | **−0.00001405** |

ゼロでは係数・局面のどちらの上限にも当たらない。
それでも敗局群は悪化方向で、勝局群の改善がそれを上回るため全体では良い方向になる。
今回の平均目的関数には「各群を必ず良くする」という条件はない。

最終状態では、係数を切った後でも13学習局面が100cpを超えるため補正が必要だった。
仮の提案で上限に触る係数は951個。局面補正後の方向と補正前の方向のcosineは約0.633。
方向はかなり変わるが、敗局群の向きは悪化から改善へ変わっている。
勝敗損失だけを見ても、同群の一次近似は補正前＋0.00002577から補正後−0.00002434へ変わる。

探索専用の最終状態も同様に、係数切り後に15局面が上限を超え、局面補正が働く。
敗局群の探索損失は補正前後とも改善方向である一方、勝敗損失は補正前には悪化方向、
補正後には改善方向だった。探索との整合と勝敗予測は同じ目標ではない。

## 将棋としての意味と、まだ分からないこと

例えば、似た金銀配置が勝局にも敗局にも登場すると、勝敗教師は同じ配置を上げ下げする
要求を出す。周辺の駒の支えや攻めの速度を別の特徴との組合せで区別できれば両立しうるが、
今回の集計だけでは、どの配置・特徴が衝突の中心かは特定していない。
「金銀の特徴が足りない」と結論して新しい厚みボーナスを足す根拠にはまだならない。

また、２つの群の方向が強く反対でも、両群を改善する別の方向がないとは限らない。
本診断は平均勾配方向と既存補正を調べたもので、共通の改善方向の存在を解いたものではない。
４状態だけの結果なので、200更新全体を通じて常に同じ働きだったとも言わない。

## 次の優先順位

1. **上限緩和・更新延長・混合率変更を先に行わない。** 今回、上限なしでも敗局群が悪化し、
   上限補正はその悪化を抑える向きに働いた。
2. 続けるなら、**同じ学習データ・同じ上限内で、勝局群と敗局群をともに改善できる方向が
   存在するか**を、小さな保存データ診断で確認する。両立する方向が見つかれば、
   特徴不足を決めつける前に更新の受入条件を検討できる。
3. 両立が難しい場合に、衝突へ寄与する特徴と具体的な局面を少数確認する。
   その結果で特徴の見直しか教師の見直しかを決める。検証局面や特殊な１手を正解にしない。

学習・対局を再開する判断はまだしない。今回も厚みの獲得や棋力向上を示す結果ではないが、
「安全側に抑えた条件が悪いから緩める」という進め方を避ける根拠にはなった。
