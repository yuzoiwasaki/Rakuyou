# 拡大した勝敗学習：256／64件・20更新、負け局面の悪化傾向が残る

2026年10月14日。[接続・尺度監査](2026-10-14-outcome-expanded-preparation.md)済みの集合で、
条件を変えず、一度だけ20更新した。決着件数は学習256・新検証64。
固定20平均候補の検証誤差は整数評価で約0.00634％改善したが、整数化前は約0.000645％にとどまる。
勝ち局面は改善する一方、負け局面・先手番は悪化し、前回の傾向が残った。
候補と結果を保存し、現行評価・release・定跡・25cp補正は維持した。

## 維持した条件

有効383／80元局面を変更せず、決着256／64件だけに勝敗損失を付ける。
学習の上限draw127件、新検証draw16件、別枠の使用済み後手draw6件は損失・勾配・学習キーから除外。
前段の不足・3件の反復除外を埋める補充はしない。
新検証80件に別枠6件を混ぜない。

現行評価からKP／PP差分0で開始し、以前の96／23件の候補を継続学習しない。
学習側の決着だけから抽出した40,052係数を更新。
損失は等重みの決着局面の平均二値交差エントロピー、予測 `sigmoid(cp/600)` と差分L2。
全学習決着件を毎回使う規則を維持し、データ拡大により全件数が96から256へ増えた。

L2=1e-6、既存RMSprop、step rate／一回の上限0.001cp、累積係数上限±0.01cp、平均化decay0.9995。
0・5・10・20を保存、20平均候補を固定。検証の結果で候補を選び直さない。
進行度・手番・駒価値・利き・玉安全度・25cp補正・定跡は保護。
通常探索・静止探索・教師生成・新規対局・追加学習・係数調整は0。

改善率はそれぞれの基準損失に対する相対値で、勝率の変化ではない。
表の誤差にL2は含めない。

20平均の学習損失は0.7018227312→0.7012679304、検証は0.6954879898→0.6954438716。
検証の整数化前損失は0.6954835041で、改善はごく小さい。
整数化後の小さな評価差が、検証平均の改善率へ影響している。

学習決着256件中155件の整数評価が変化し、結果に近づく方向138件、逆方向17件。
新検証64件中35件が変化し、近づく方向19件、逆方向16件。
以前の検証23件と今回の64件は異なる集合なので、改善率の大小だけでデータ拡大の優劣を断定しない。

学習側では先後・勝ち・負け全層の平均誤差が改善したが、検証では負ける配置を低くする効果が揃って伝わらない。
データを増やしても、前回と同じ「勝ち局面は改善、負け局面は悪化」の傾向が見られた。

学習・検証は別対局・別runに分けているが、run群は過去にも使用したもの。
棋譜は歴史的な自己対局でruntimeの同一性に限界があり、層別抽出の比率も自然な勝率分布ではない。
今回の誤差改善を、そのまま実戦の勝ちやすさ・負けにくさと解釈しない。
