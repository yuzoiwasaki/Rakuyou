# 新米長玉2局：実戦手と現行候補の比較、最初の模倣学習案

2026年10月12日。[入力準備](2026-10-12-historical-two-game-learning-preparation.md)済みの2局から、
各局の後手22・42・62・82手目の着手前を固定して、実戦手と現行評価の候補を比較した。
8局面・16探索を一度ずつ実施し、全てdepth15完了・合法PV・cp値として監査できた。
学習更新は0。今回の結果だけで実戦手を良手・悪手に分類せず、次は小さな模倣学習の準備を提案する。
現行評価・release・定跡・25cp補正を維持している。

## 固定した比較条件

2局の同じ4手数を使い、評価値、勝敗、手の種類、過去の解析順位で局面を選ばなかった。
手数はその手を指す直前の番号。共通序盤を過ぎ、2局とも到達する82手目までを対象にした。
これは学習／検証の分割ではなく、後手の指し方を理解するための診断。

各局面について、候補手を制限しない探索と、実戦手だけに `searchmoves` を制限した探索を各1回。
Depth15、Threads1、Hash64MB、MultiPV1、新米長玉ON、定跡OFF、30秒上限、毎回fresh process。
既存の隔離済みbaselineをSHA確認して使った。上限16探索、再試行・補充・自動深掘りは0。
planと全8局面を探索前に保存し、input側のattempt markerで一度限りの比較に固定した。

評価値は後手視点。両欄は探索条件が異なるため、差を実戦手の損失や棋力の差とみなさない。

第一候補と実戦手の一致は2／8。銀の前進が一致する例もあり、相違する例には
玉を５三へ出るか５一へ引くか、歩の打ち直し、端歩・中央歩の順序などが含まれる。

プレマッチ82手目はどちらも△７三桂打なのに449cpの差が出た。
また、候補を限定した方が無制限の第一候補より高い例もある。
固定depthでも候補制限によって探索木が変わるため、今回の別探索の点差は同条件の候補順位ではない。
この差から「一定cp以上悪い実戦手は除く」という教師選別は行わない。
後半の大きな負評価も、この診断だけで敗因・悪手とは断定しない。

## 現行評価からの学習に使える方式

旧 `--learn` を再初期化なしの継続学習へ小改造するだけでは済まない。
`src/learning.cc` の `CopyParams` は学習用の浮動小数・拡張パラメータからpacked評価表を再生成する。
現行 `params.bin` のpacked値を、この拡張モデルへ一意に戻す処理は確認できていない。
ゼロ差分で基準を保つには、基準を固定したまま加算する別経路が必要。

最初の案は、既存の**玉と駒の位置関係（KP）と、玉以外の駒同士の位置関係（PP）**に、
棋譜の手を好む方向の小さな差分を加える方式。
「厚い金銀」のような新しいテーマ特徴を人が作らず、技巧が既に持つ一般的な駒配置の項を使う。
全表を初期化せず、今回の学習末端で現れるキーだけを候補の差分として保持する。

KPは序盤・中盤・終盤の3段階を対象とし、4番目の進行度レーンは固定する。
PPは序盤・終盤の評価レーンだけを対象とし、手番レーンは固定する。
駒価値、進行度、手番、利き・玉安全度の表、25cp補正、定跡は更新しない案。
PPの対称な表参照や先後反転で整合するよう、nativeのキーと差分反映を監査する必要がある。
これは既存の1特徴・2係数pilotにはない接続で、まだ実装していない。

## 最初の小規模実験案

1. 今回の固定8局面を維持し、実戦手と現行第一候補が異なる6局面を、指し手の対比較にする。
   同じ手の2局面は、模倣の比較信号がないものとして更新せず、確認記録に残す。
   差の大小で残す手を変えない。各局3対ずつとなる。
2. 各対のPVと静止探索末端を固定し、KP・PPのキー・出現数・整数化前の評価を抽出する。
   学習損失は「実戦手を代替手より好む」指し手の対比較。探索cpを正解値に回帰する方式とは異なる。
   両局とも後手敗北なので、勝敗損失は初回無効とし、結果ラベルを保持する。
3. 現行評価から差分0で、一度だけ20更新。係数差分上限±0.5cp、
   準備した局面全体の変化上限10cpを案とし、0・5・10・20を保存する。
   正則化の強さは、抽出キー数と学習側の初期勾配を確認して実行前に固定する。
   以前の2係数実験のL2を、多数のキーにそのまま流用しない。
4. 指し手の対の評価差が実戦手を好む方向へ動いたか、整数化で残ったかを確認する。
   以前の学習集合へは混ぜず、既存の別棋譜の検証35局面を評価差・先後・drawの点検に使う案。
   この35件は過去の実験で使用済みであり、未見の強さ検証ではない。
   2局の隣接局面をランダムに分割して、独立した検証とは呼ばない。
5. 実戦手の順位改善を、勝率改善や新米長玉の棋風全体の獲得と解釈しない。
   大きな差を逆転するまで係数を増やさず、結果が小さくても追加調整・自動拡張・採用はしない。

6対では、本家の指し方を学べるかを確認する入口にとどまる。
両敗局からの模倣なので弱い指し方も教えるリスクは残り、教師の選別や勝敗の学習は次の設計課題。
なお今回の固定depth比較の不安定さを踏まえ、PVの固定による変化は探索挙動の改善とは別に扱う。

次に進めるなら、まず上記のキー抽出・ゼロ差分・正則化単位の準備監査まで。
教師候補や更新条件を見直す場合は実行前に相談し、現行評価への採用は別判断とする。
この案への合意と、必要な差分経路の実装・監査が済むまでは実学習しない。
