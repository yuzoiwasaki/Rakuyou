# 対局開始局面と運用定跡の照合

## 結論

手作りの開始局面は、現在の運用定跡から自然に進めた局面とは異なる。
今回の７勝８敗１分はその開始条件での結果として残すが、運用時の新米長玉の
強弱や、学習による厚みの改善を判断するには条件のずれがある。
このずれが敗因だったかは未確認であり、結果を取り消す理由にはしない。

## 保存データで確認したこと

元の８局面と別開始８局面について、初手から12手目までの各局面を
運用定跡 `books/shin-yonenaga-book-v1.txt` の17登録局面と照合した。
手順文字列ではなく盤面・持駒・手番を比較した。
16開始手順と、17定跡項目の指し手までの計33手順は既存のnative refereeで合法性を確認。
探索、追加対局、評価値の計算は行っていない。

| 開始条件（元・別開始共通） | 定跡と一致する選択／最初の不一致 |
| --- | --- |
| 先手新米長玉・対四間／三間／中飛車 | ３手目は定跡なら▲７六歩、手作りでは▲３八銀 |
| 先手新米長玉・対居飛車 | 途中に定跡登録局面なし |
| 後手新米長玉・対四間飛車 | △５四歩・△４二銀は一致。８手目は定跡なら△５三銀、手作りでは△７二銀 |
| 後手新米長玉・対三間／中飛車／居飛車 | 途中に定跡登録局面なし |

不一致後の12手目までに定跡登録局面への合流はなかった。
全16の開始時点も登録局面には一致しない。ただし定跡外に出ること自体は普通であり、
「登録なし」は悪手や不適切な局面という意味ではない。

先手側は、角道を早く開ける運用定跡に対し、先に▲３八銀・▲３九玉・▲６八銀を
指定していた。別開始では11手目を▲７六歩にしているが、その間の駒組みも
相手の手も既に決まっており、３手目の▲７六歩と同じ条件にはならない。

後手四間飛車戦では、定跡は８手目に△５三銀と上がり、その後△７二銀・△７一玉。
手作りでは△７二銀・△７一玉を先に指定し、元の開始は12手目に△５三銀、
別開始はそこで△９四歩とした。別開始では銀が４二に残り、中央への進出が遅い。
さらに相手の玉も、定跡本線の▲３九玉に対し、手作りでは４八に残っている。
自分の銀の手順だけを比較した試験ではない。

運用定跡は先手６項目・後手11項目で、後手側は対先手四間飛車が中心。
手作り試走の４戦型均等という構成は、この定跡の対応範囲とも異なる。

## 解釈の範囲

別開始では新米長玉側が両版合計１勝14敗１分で、開始直後の探索評価も
両版とも同側に厳しかったことは[結果レポート](2026-10-18-alternate-match-result.md)の事実。
今回、運用定跡との手順・配置のずれも確認した。
しかし「銀の遅れが負けを生んだ」「運用定跡なら勝てる」は仮説である。
元の開始でも同側の初期評価は低く、今回の照合だけでは説明できない。

同じ開始から候補と現行版を先後交換する比較には引き続き意味がある。
一方、開始局面の性質によって評価変更の効き方が変わる可能性があるので、
旧条件の９勝５敗２未決着と別条件の７勝８敗１分を単純合算して採否を決めない。

## 次に優先すること

1. **既存の運用定跡に沿った入口で、同じ候補を比較する。** 新たな駒組みを
   手作りせず、現在の定跡に既に記録された手順の末端を使用する案を優先する。
   他項目の親手順へ続くものを除くと、記録手順上の末端は先手２・後手５の計７本
   （長さ９・７・６・６・14・16・16手）。全７本を使い、先後交換の14局とする案。
   評価値や勝敗を見て入口を選ばない。実装前に盤面重複・合法性・定跡への再合流を
   再確認し、対象と条件を固定する。この７本は独立標本ではなく近縁の分岐である。
2. **問いを限定する。** 確かめるのは「運用定跡に沿った入口の先で候補がどう働くか」。
   定跡選択そのものの性能や、全戦型での棋力ではない。対局中は従来同様book OFFとし、
   同じ深さ・実行条件で比較する案が小さく観察しやすい。
3. **厚みは別に見る。** 勝敗に加え、銀が中央へ出て歩や駒を支えたか、玉を薄くして
   攻め急いだかを保存棋譜で確認する。△５三銀を通っただけでは学習成果と数えない。
   入口で指定された配置と、その先で候補が選んだ指し方を分ける。

初期局面から定跡ONで対局する方法は運用に近いが、定跡分岐の偏りも加わるため次段階。
同時間対局、大量の追加対局、再学習、混合比変更は今回の条件整理より後に置く。
現候補の採用は保留。悪い結果を良くするための開始局面の選び直しにはしない。
