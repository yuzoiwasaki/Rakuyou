# 両群確認型の混合学習：敗局群の改善は検証にも移った

[固定計画](2026-10-20-temporal-guarded-plan.md)どおり200更新と最終集計が完了した。
早期停止はなく、すべて群を均した方向で進んだ。
学習局面の敗局群だけでなく、検証局面の敗局群の勝敗損失も改善側へ変わった。
ただし勝局群での改善はほぼ失われ、全体の改善幅は通常混合と近い。
棋力・厚みの向上を示した段階ではない。

## 何が起きたか

通常方向は200更新すべてで、21段階の幅を試しても敗局群の混合損失・勝敗損失を悪化させた。
そのため全更新で群を均す方向へ切り替えた。切替後は半減なしで受理され、
71更新で既存の局面上限補正が働いた。上限・教師・混合率を変更していない。
停止理由は予定した `update_budget`。

群別の滑らかな損失が単調改善することは受入条件そのものなので、
学習側の改善だけを新たな成果とは数えない。
また、通常方向の棄却を経てから切り替えるため、200更新でも通常混合より試行数は多い。

## 将棋としてどう読むか

通常混合では、勝った棋譜の局面をより高く見積もる利得が、
負けた棋譜の局面を過大評価する悪化を埋め合わせていた。
今回はその交換を認めずに学習でき、検証の敗局群でも最終結果との整合が改善した。
「勝った形への適合を控え、その分、負けた側の見積りも修正した」と読むのが近い。

しかし、敗局中にも互角や優勢の局面はある。最終結果に近付いたことだけでは、
攻めを急ぎすぎる指し方や守備駒を交換する判断が直ったとは言えない。
金銀の支えや前進を直接評価した結果でもない。厚みの個性は今後の指し手・局面確認が必要。

## 次の優先順位

1. この候補を固定し、現行版との少数の同一局面探索比較へ進む案を優先する。
   元局面／追加局面、先後、勝敗を偏らせず、評価変化の大きさや都合の良さで選ばない。
   指し手が変わった場合に、攻めと守り、金銀の支え・交換後の働きを見る。
   特定の１手を正解ラベルにはしない。
2. 更新延長・混合率探索・上限緩和は保留。今回の仮説を検証する学習は予定どおり完了した。
3. 対局・現行評価への採用はまだ行わない。検証は既に見ている局面であり、
   全体の小さな差や敗局群の改善から勝ちやすさ・負けにくさを断定しない。

このターンでは結果の読み戻し・記録だけを行い、新規探索や学習は実行していない。
