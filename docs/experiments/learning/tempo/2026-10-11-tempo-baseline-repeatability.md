# 同じ基準評価による通常探索の再現性確認：3局面・6探索

2026年10月11日、ソース基準 `67d450f`。
[通常探索比較](2026-10-11-tempo-full-search-comparison.md)で差が目立った3局面を、
基準パラメータだけで各2回再検索した。前回を含む各3回で、cp・bestmove・PV・nodesが
すべて一致した。この限定した対照では、同一基準の起動ごとの変動は観測されなかった。
候補評価の採用と棋力判断は保留する。

## 方法

前回の絶対cp差が最大の1局面と、bestmoveが変わった2局面を固定して選んだ。
全体の再現性を推定する無作為標本ではなく、目立った差の診断である。

- depth12、MultiPV1、Threads1、Hash64MB、ShinYonenagaGyoku ON、OwnBook OFF、Ponder OFF。
- 検証済みの基準環境 `baseline/bin/release` のみを使用し、各検索で新規プロセス。
- 3局面×2回＝最大6探索、各30秒。timeout時の再試行・延長・深掘りなし。
- 前回reportと準備manifestのSHA、対象局面との対応、runtimeコピー14件、運用6件を検証。
- 独立した `baseline-control-attempt-v1.json` を準備環境に排他的に作成。
  前回の24回比較の実行マーカーを解除せず、別名出力による誤った再実行も拒否する。
- ルート再生とSFEN一致、完了depth12、boundなし、bestmoveとPV先頭の一致、合法PVを検査。
- 候補の新規探索0、追加学習0、対局0、配備false。

```sh
python3 tools/check_tempo_search_repeatability.py \
  results/learning-pilot/2026-10-11-full-search-preparation-v1/manifest.json \
  results/learning-pilot/2026-10-11-full-search-comparison-v1/report.json \
  --output results/learning-pilot/2026-10-11-baseline-repeatability-v1
```

この実行は6探索で終了済み。再実行はマーカーにより拒否される。

## 解釈

前回の通常探索比較では同一基準の対照がなく、起動ごとの探索変動を分離できなかった。
今回、その対照を追加した3局面では、基準の結果がそのまま再現された。
この範囲で「今回の基準結果は起動のたびに大きく揺れる」とする説明は支持されない。
Zobristキーは起動時に乱数生成されるが、それが前回の差を生んだという証拠はない。

基準と候補の差は引き続き残る。ただし候補側の通常探索は各1回だけで、
候補自身の再現性は未確認。他の9局面、別の深さ・Hash・局面条件も今回の対照対象外。
全エンジンの決定性や、12バイトの変更だけで必ず同じ差が生じることまでは証明しない。

手番の微小な差分が主探索の経路・枝刈り・手順序を変える可能性はあるが、
それぞれの寄与を今回の観察だけで特定しない。
今回も候補手の正しさ、棋力、引き分け確保能力、勝率は評価していない。
