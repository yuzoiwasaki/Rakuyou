# 玉近傍の支持された金銀を数える小実験（2026-11-08）

## 変更と範囲

ユーザーの「薄い新米長玉では受けを重視したい」という方向を受け、既存の利き情報を使う**新しい限定補正を1つ**試した。各側の自玉からチェビシェフ距離2以内にいる未成の金銀のうち、そのマスへの自分の利きから自玉の幾何利き1本を除いても1本以上残る駒の数を `N` とする。補正は `10 × (N先手 − N後手)` cp。`PackedScore(raw,0,raw,0)` を既存の玉安全合算へ足し、手番項と進行度は変えない。孤立駒への罰、敵の攻め、持駒条件や支持歩ボーナスの変更は含めていない。これは守備駒の働き全体を評価する式ではない。

運用ソース・`bin/`・評価データ・従来の支持歩ボーナス10を変更せず、隔離した同一エンジンを環境値0/10でfresh起動した。[試作パッチ](2026-11-08-near-guard-prototype.patch)は元 `evaluation.cc` への差分で、原本の著作権表示を保持する。ブランチは作成していない。
