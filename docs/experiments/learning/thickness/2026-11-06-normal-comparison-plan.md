# 新米長玉＋加点0/10：同じ通常相手との比較計画

加点を変えず、新米長玉＋0と新米長玉＋10を同じ通常設定に対して比較する。
第6局の受け方を加点10の原因と決めつけず、既存の小診断はそこで区切る。
この文書は実装前に固定した設計であり、本対局はまだ実行していない。
設計・最終レビューはAstra、確定した実装・検査はSolが担当する。

## 集計と解釈

新米長玉0/10を別々に、勝・敗・正式引分・未決着・エラー・未実行の数と先後内訳を示す。
得点率は決着した勝敗と正式引分のみを分母にし、`(勝 + 0.5×引分)/(勝+敗+引分)`。
分母0なら数値を出さない。未決着・エラー・未実行は0点や引分に換算しない。
16局終了でも未決着があれば、全16局から棋力を推定したように見せない。

各開始IDの2結果を並べ、両方に正式結果のある組に限り
`新米長玉10の得点 − 新米長玉0の得点`（勝1、引分0.5、敗0）を記載する。
同じ組集合での両設定得点率と平均差も併記し、対応のない完了局の差を主要比較にしない。
比較可能組数・未完組数を明示する。途中の勝敗を見て局数・係数・開始局面を増減しない。

内容確認では全8組の両局を対象に、総手数32/48/64手の同じ時点を入口にする。
その前に終局していれば最終局面と終了時点を明示する。結果差が出た組と両設定が負けた組は
特に負け方を確認するが、勝った加点10の好例だけを抽出して評価しない。
手厚さ、金銀の働き、受けの穴、戦術的な見落としと好みを分けて記述する。
異なる続きになった局面同士から特定の手の因果を断定しない。
必要な追加探索は今回の16局には含めず、結果確認後に別途判断する。

この試験で比較できるのは、固定された開始局面群で同じ通常相手に対する加点0/10の差。
新米長玉OFF同士の対照はなく、新米長玉設定そのものの効果と強制開始形の効果は分離しない。
8組は似た局面を含み、16個の独立標本とは扱わない。微小な弱化や同等性は証明できない。
支持特徴の出現数や加点を含む自己評価値の上昇を、棋風・棋力改善の代用にしない。
結果が五分でも自動採用、既定値変更、係数調整、学習はしない。
