# 馬を封じ込めてじっくり指す構想：次の判断

組7の△8二玉はユーザーにとって中立。正例や推奨手にしない。
望むのは、▲4一馬の圧力に対して攻め急がず、自陣の連携を保ちながら指す構想。
加点10の調整ではなく、この構想を既存評価・探索がどう扱うかを次の対象にする。
今回は既存コードと保存PVを読むだけで、探索・評価変更・補助ツール追加は行っていない。

## 既存コードから言える範囲

`src/evaluation.cc` の `EvaluateSlidingPieces` は角・馬の対角線について、
最初の駒または盤端への到達点、両玉の位置、到達先の駒を評価する。
馬の縦横1マスの利きはこの角用項には入らないが、盤全体の利き・駒位置を扱う
別項に表現経路がある。`EvalParameters::two_pieces` も馬と金銀等の位置関係を持つ。
したがって、馬の働きや包囲に関係する配置を全く見ていないわけではない。

一方、これらの項は「馬が有効に進出できず、その抑えが相手の応手後も維持でき、
抑える側の金銀が自玉を守り続ける」という一連の条件を直接判定するものではない。
利きの総数や対角線の長さを減らしても、急所への1経路が残れば十分な封じ込めとは限らない。
逆に多数の移動先があっても、有効な攻めにつながらない場合はある。
既存項で表現できる部分、その重み、複数駒の組合せによる働きを分けて考える。
現状のコード読解だけで、重み不足や新項目の必要性は確定しない。

通常探索は静かな整備手も生成するが、`src/search.cc` の実現確率・LMRで深さを削減し、
静的評価を使う枝刈りも行う。該当する静かな手の枝刈りは根局面を除く。
深さ削減は根でも起こり得るが、alphaを超えた場合の再探索がある。
静止探索は捕獲・王手等を中心に進め、一般の静かな整備手順を全て継続するものではない。
長期の整備を十分評価するには、読みと終端評価の双方が関係する。
今回の候補が実際に削減・枝刈りで損をしたという記録はなく、探索変更の根拠にはしない。

## 保存済みの具体案がある

`results/teatsui-pair7-diagnostic-2026-11-07/search-05.json` の
`all_pv_infos` には、加点10・**41手終了後**からの深さ7〜11で、
次の整備案が既に出ている。

> △6三金（5二から） ▲6五桂（7七から） △4二銀（5三から）

深さ8〜11ではこの後に▲1六歩、△8二玉が続く。
最終深さ14では△5五歩を選んだ。同じ根局面の保存探索の途中に整備案が現れた事実であり、
整備手を一切候補にできないとは言えない。ただし、各深さの候補は同条件の固定候補比較ではなく、
最終時点でこの案をどこまで読んで退けたかや、どちらが優るかは分からない。

この3手後の配置には、検討に値する具体的な関係がある。
6三金は4一馬の対角線上に位置し、7二金と6二飛から支えられる。
5二を空けたことで6二飛の横利きが4二銀へ通り、その銀は5一・3一にも利く。
さらに銀は6五桂が利く5三から移る。
これらは保存手順上の幾何的関係であり、ピンや守備負担、交換後まで含む安全性の証明ではない。
馬には他の経路もあり、この配置だけで封じ込め成功とは呼ばない。

この入口は、35手終了後の馬侵入直後とは異なる。
既に△2四歩・△4四角打・△2五歩等が入った41手後であり、
この整備案が有望でも、36手目の△2四歩が正しかった／悪かったとは判定できない。
途中の△8二玉もユーザーの中立評価のままとする。

## 次の判断を限定する

まず上の保存案を「馬の有効な進出を抑えること」と「自陣の連携を保つこと」の
具体的な比較候補にできるかを検討する。必要なのは最善手のユーザー指定ではなく、
封じ込めという目的と候補手順の働きが対応するかの確認。
新しい注釈画面や、元の0/10診断の再実行は必要ない。

ユーザーは、馬を物理的に閉じ込め続けること自体よりも、有効な攻めへの参加を抑える
ことが中心で、馬の退却や無理のない交換も含む、という理解を確認した。
先手は馬を作って「もたれている」。すぐ具体的な攻めがあるわけではなく、後手が攻めた
反動で駒を得て、そこから陣形を崩そうという狙いとの説明。したがって後手はその狙いに
乗らず、あえて攻めずにじりじり指す方がよいというユーザー判断である。
馬の存在だけによる緊急の受けや、一律の不攻めを求める話ではない。
この構想理解を特定手の最善性、△6三金の承認、探索上の優越の証明に置き換えない。

ユーザーはここで全体の現在地と次の方針の整理を希望した。以下の候補比較は選択肢として
残すが、自動で実行する次工程にはしない。支持形の小加点による棋風実験という元の目的に
戻り、形の好みと、相手の狙いに応じて維持・仕掛けを選ぶ問題を分けて検討する。

候補が目的に合うと判断でき、技術的な比較が必要になった場合に限り、次の別計画を検討する。
41手終了後の同一履歴で△6三金と△5五歩を比較し、最初は加点0に固定する。
相手の応手を都合よく固定せず、各候補への反撃と交換後の連携を同じ探索条件で見る。
後続の△4二銀は比較する構想であって、相手の別応手にも必ず指させる手ではない。
探索資源・停止規則・局数は実行前に別途固定する。今は探索を許可した計画ではない。

判断の分岐は次の通り。

- 整備案に具体的な難点があれば、この局面を「良い備えを選べない」失敗例にしない。
- より十分な読みで整備案が有望なら、探索の扱いと評価の双方を候補原因として残す。
  深くして選択が変わっただけで、枝刈りが原因と断定しない。
- 整備の働きに関する評価上の不足を具体化できてから、既存項の重みと不足する関係を比較する。
  同じ局面での自己評価差だけでは不足の証明にならない。

支持形10、運用既定0、学習停止、未採用の状態は維持する。
馬の存在・移動先数・玉への幾何的な利きだけによる一律減点や、
「じっくり指す」こと自体への加点は今回の案に含めない。
