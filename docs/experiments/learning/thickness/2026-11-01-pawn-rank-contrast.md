# 高美濃＋５六銀型と、５筋の位の違い

先手は振り飛車、後手が新米長玉。追加探索・学習・評価コード変更はしていない。

## 判断と訂正

- 助手は先手の６五歩・５六銀・４七金を両PVで「部分的な厚み」と解釈した。
  ユーザーは、厚みと呼ぶには微妙で、普通の高美濃＋５六銀型に見えると訂正。
  これは「厚みが絶対にない」という断定ラベルにはしない。
- ユーザーは後手の指し手について、加点10の方が意図が明確で面白く、好みと評価。
  加点0の△８三飛〜△８二玉には人間的な違和感がある。
  先手陣の厚み判断と、後手の指し方の好みを別々に扱う。
  好ましい読み筋が出たことは、厚み項の意味や棋力改善の証明ではない。
- 当初の追加指摘：この例で５七歩が５五歩にいれば、位を取っていて厚みに見える。
  ただし図の確認後、相手の５四歩があるのでやや微妙と補足された（下記参照）。
  他の駒を変えず歩を置き換えた仮想配置として保存する。
  ５六銀を越える歩の合法手順や、実際に２手使って位を取れることを意味しない。

## 次の設計への含意

現行項は６五歩の支持関係だけで既に1なので、５五歩を加えても1のまま。
この対比を区別できないことが確認できた。ただし、特徴を複数組の個数に変えて
加点を増やせば解決するとは限らない。支持の重複を強さと取り違える危険がある。

「歩と支える銀が同じ筋」という条件は、今回の２図を区別できる候補ではある。
しかし、以前のA59の６五歩・５六銀・６七銀は同じ筋ではなく、ユーザーが
相手の攻め駒を抑える部分的な厚みと認めた例。正面支持だけに絞ると失う。
正面支持を厚み全体の必要条件にしたり、斜め支持を一律に除外したりしない。

次の作業は、今回の原図／５五歩仮想図／既承認A59を並べた小さい対照集合で、
位の場所と広がり、支える金銀の配置、相手の進出を抑える働きを比較すること。
この３観点は検討軸であり、ユーザーが確定した数値特徴ではない。
まず既存例をどう説明できるかを確認してから、必要な追加対比を相談する。
現行係数の増量や大量学習はまだ行わない。

## 図の確認後の補足：押さえ返しと効力

ユーザーは加点10の後手の金が盛り上がる形を改めて好評価し、
実験の方向性は良い気がすると述べた。これは有望な棋風上の観察として保持する。

一方、先手の仮想５五歩については、相手も５四歩を置いているので厚みと呼べるかは
やや微妙と補足。５四歩がなければ威張っていて厚みだと思う、との判断。
さらに、この形は厚みの先に相手の玉も攻め駒もなく、効力としては薄そうと指摘した。
「５五歩があれば厚み」とする無条件の肯定ラベルを撤回する。
「効力が薄そう」は総合的な形勢不利や無価値という判定ではない。

追加図：`results/thickness-dialogue/repaired-14-review/opposition.html`。
加点10・3手先を元に、原図、５五歩仮想図、そこから後手５四歩を省いた図、
既承認A59の４図を並べた。５四歩は持駒に移さず盤外に省略し、その旨を明記。
省略前後は盤上の５四歩だけが違うことを確認した。合法な局面遷移・駒得・
エンジン評価の比較には使わない。A59の持駒は先手銀歩、後手桂歩。

## 観察項目を分ける設計

次の段階では単一の「厚みあり」ラベルに押し込めず、以下を別々に記録する。

| 観察項目 | 今回わかったこと | まだ確定しないこと |
| --- | --- | --- |
| 支持関係 | 高美濃＋５六銀でも現行項が発火する | 支持だけで厚みと呼べるか |
| 空間の確保・押さえ返し | ５五歩と相手５四歩の有無で印象が変わる | 対向歩がある全局面を除外してよいか |
| 働き先 | 玉への圧力・攻め駒の抑制が乏しければ効力は薄そう | 近くの駒数や距離だけで機能を測れるか |
| 棋風の好み | 加点10の後手の金の盛り上がりは好ましい | その変化が現行項の意味を裏付けるか、棋力が上がるか |

この分離は設計上の観察軸で、まだ数値特徴や学習ラベルではない。
まず原図／対向歩あり／対向歩なし／A59を説明できるか確認し、
実装前に保存局面で正面の対向歩と支持の方向を別々に計数する案を検討する。
相手の玉や攻め駒の機能は当面盤面レビューで判断し、近接だけで自動認定しない。
対向歩なしを必須条件にしたり、働き先が薄い形を一律ゼロ点にしたりはしない。
既存評価にも利き・玉安全度があるため、効力を数値化する際は重複も確認する。
今回、評価コード・係数・運用設定の変更や探索・学習は行っていない。
