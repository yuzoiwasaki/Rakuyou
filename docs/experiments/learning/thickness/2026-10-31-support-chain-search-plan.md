# 支持関係の試験項：固定28局面、0/10の探索比較

2026年10月31日。ユーザーの継続指示により実施。
対象は計数監査で固定した既存14局の通算32・64手目、28局面。
全て既知の開発用局面であり、未見評価や棋力検証ではない。

- 同じO2/assert有効の試験バイナリを使用。各局面・各設定で新規プロセス。
- `ExperimentalSupportChainBonus` は0と10。その他は深さ15、1thread、hash64、
  新米長玉ON、定跡OFF、ponderOFF。手順は初手から渡す。
- 各探索120秒上限。最大56探索。失敗・timeoutを残し、再探索や局面の補充をしない。
- 今回は追加の候補手固定探索・対局・学習を行わない。
- 探索前に28局面を既存native probeで再生し、監査時SFENと照合した。
  ソースと試験バイナリが実装検査時manifestに一致することも確認した。
- バイナリ、params、progress、probability、実行スクリプトのハッシュを開始前に固定。
  運用の実行ファイルやデータは書き換えない。

ローカル保存先は `results/thickness-dialogue/support-chain-search-2026-10-31/`。
`plan.json` を実行前に排他的作成し、各探索のコマンド・出力を個別JSONへ保存する。
同じ出力先への自動再実行は拒否する。
Pythonの専用実行スクリプトは実験用としてローカルに保持する。

結果は、完了・到達深さ、bestmove/PVの違い、具体的な配置の変化を確認する。
加点を含む候補の評価値上昇を、改善の根拠にしない。
指し手が変わらなくても、子局面の評価まで全く変化していないとは言えない。
新しい係数や対局へ自動的に広げず、この比較の記録を一区切りとする。
