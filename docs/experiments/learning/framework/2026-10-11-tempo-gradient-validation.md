## 符号と目的関数

`tools/learning/core/tempo_objective.py` は、末端局面・進行度を固定した手番差分3係数のモデル。
根拠は [評価の内分・手番処理](../../../../src/evaluation.cc) と
[学習側の進行度係数](../../../../src/learning.h)。
実エンジンの最終cpは整数に丸められるため、その離散関数自体を微分しない。
現在の整数評価を出発点に、丸め前の差分を加える滑らかな近似を定義した。

- 進行度を `p=floor(progress*65536)/65536` に固定する。
- `p<0.5` の内分係数は `(1-2p, 2p, 0)`、それ以降は `(0, 2-2p, 2p-1)`。
- 手番係数は末端の**手番側評価**に、先後とも `+1/2` で入る。
  評価内部の後手での引き算は、最後の手番側への反転で相殺される。
- ルートと末端の手番が同じなら `s=+1`、異なれば `s=-1`。
  末端のベース評価と差分の両方にこの符号を掛ける。

ベース末端cpを `b`、手番差分を `delta`、内分係数を `w` とすると、
ルート手番側の予測は `f=s*b + sum((s/2)*w[i]*delta[i])`。
教師cpはルート手番側のまま保持する。

損失は次の**平均**二乗誤差と、差分だけへのL2である。

```text
gain = 1/600
y = sigmoid(gain*f)
t = sigmoid(gain*teacher_cp)
L = mean((y-t)^2) + (lambda/2)*sum(delta[i]^2)
dL/ddelta[i] = mean(2*gain*(y-t)*y*(1-y)*(s/2)*w[i]) + lambda*delta[i]
```

今回は `lambda=1e-4` を数値検証用に使用した。係数の単位はcp、L2はcp差分に掛ける。
バッチの件数を増やしても正則化の重みが変わらないように平均化する。
これは学習時の最適な係数を探索・決定したという意味ではない。
sigmoidはoverflowを避ける形で計算し、clippingは使わない。
既存RootStrapの表示損失と導関数の不一致を継承せず、上式の導関数を使う。
既存 `src/learning.cc` は変更していない。

## 検証結果

```sh
python3 -m unittest discover -s test -t . -p test_tempo_objective.py -v
python3 tools/learning/checks/check_tempo_gradient.py \
  results/learning-pilot/2026-10-11-preparation-v2/manifest.json \
  --output results/learning-pilot/2026-10-11-input-validation-v1/tempo-gradient-v1.json
```

中央有限差分の幅は各係数0.001cp。
許容誤差は `1e-9 + 1e-6*max(abs(analytic), abs(numeric))` とした。
非ゼロのdeltaを評価する場合もPythonの式内だけであり、パラメータデータや
ネイティブエンジンの評価値へ適用していない。

| 対象 | ケース数 | 最大勾配絶対誤差 |
| --- | ---: | ---: |
| 合成末端 | 336ケース、1,008係数 | `5.5952e-14` |
| trainの固定ルート、deltaゼロ | 1,024局面の平均損失、3係数 | `7.0769e-16` |
| 同じtrain、式内delta `(0.25,-0.5,0.75)` | 平均損失、3係数 | `1.6377e-15` |

合成検証には先後ルート×先後末端、進行度0／0.25／0.5の前後／0.75／1、
末端cp−1200／0／1200、ゼロ・非ゼロの式内delta、L2の有無を含めた。
実データはtrain1,024局面（先手513／後手511）のON静的評価を用い、
ルート自体を固定末端として扱った。進行度範囲は0.18857〜0.89007。
実際の静止探索PVや仮想の探索末端は使用していない。

ゼロ差分でのtrain静的損失は0.01751459597、勾配は
`[5.52446e-7, 1.05913e-7, -2.71244e-7]`。
歴史的な探索cpと現在の静的評価の、限定された抽出集合上の値である。
棋力の指標、全局面での改善可能性、最適解の証拠として扱わない。
validation/testの教師品質・損失は計算していない。

新しい7テストは、両色の手番符号、末端の偶奇反転、進行度の量子化と境界、
平均化とL2、ゼロ残差、飽和域の安定性、有限差分、異常入力拒否を確認し、成功した。
