## 懸念と結果の解釈

- **初回の効果は限定的**：手番3係数の検査であり、玉の安全度や駒組みの特徴を
  学習する段階は後続。滑らかな損失が下がっても整数cpや実際の手が変わるとは限らない。
- **棋力向上は未証明**：64局面は少なく、同じエンジンの過去探索を教師にしている。
  損失低下は教師への適合であり、勝率改善の証拠ではない。
- **データの偏りと由来**：序盤研究・自己対局に偏り、長い共通手順の相関が残り得る。
  保存JSONのSHAは照合済みだが、当時の評価関連バイナリの同一性は未証明。
- **固定末端の限界**：差分を付けた後の再探索やPV切替はまだ検証していない。
  原版の圧縮教師境界と同様に、ルート以前のNode履歴も含めない。
- **drawの意味**：現在のdrawは手数上限終了であり、正式な引き分けや後手勝ちに
  置換していない。今は探索cpとして利用し、勝敗による評価は別に扱う。
- **実行経路とバックアップ**：実データの更新経路は未実行。ローカルコピーは
  同じボリューム上にあり、外部バックアップはまだ行っていない。

原版の `--learn` にも、引き分けの二値処理やRootStrapの損失・勾配不一致等の問題がある。
今回の実験入口は該当経路を使わず、元trainerの全面的な修正は行っていない。
