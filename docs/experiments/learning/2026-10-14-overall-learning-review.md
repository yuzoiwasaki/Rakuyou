2026年10月14日。玉周囲の安全度、金銀連結、支えられた位取り・金の前進、
新米長玉2局の模倣、自己対局の勝敗学習、データ拡大、進行度重み付けを通覧したレビュー。

## 総合判断

**初期の動作確認としては妥当だった。ただし途中からは「安全に学習できるか」の条件を
引き継ぎすぎて、「厚みや棋力に役立つか」を判断する実験としては弱くなっている。**

現時点で採用を勧めにくいというユーザーの感覚には同意する。
一方、厚みの方向性や勝敗学習そのものが失敗した、と結論する材料もない。
次に変えるべき中心は特徴の種類より、望む指し方を何で教え、どれだけ変われば、
何をもって成功とするかという実験設計である。

## 進め方の妥当性

現行評価を固定した差分学習、対局・run単位の分割、勝敗の向きの確認、
打切り引き分けの扱い、整数化前後の比較は適切だった。
元の技巧の学習は評価を初期化するため、別の入口を作ったことにも理由がある。
探索評価の上昇をそのまま強化と呼ばず、△５二金への切替を追加確認した姿勢もよい。

玉周囲→金銀連結→支えられた位→金の前進と、具体的な形から理解を進めた順序は自然。
▲４五金の前方が押さえられていても、支え役の▲５六金が歩で攻められる反例を
見つけたことは、実際の成果である。

問題は、その後も小さな更新・少数局面・固定末端の誤差を中心にテーマを替えたこと。
候補を安全に作る仕組みはかなり確認できたが、指し方を十分に変え、その良否を
測る段階にはほとんど進んでいない。

## 主な制約：事実と仮説

### 目的と教師の関係

厚みの初期実験が教えているのは、現行エンジンが深く読んだ評価に近づけること。
「多少の評価差なら厚い構想を選んでほしい」という好みは教えていない。
例えば▲６五歩・▲７五歩を▲７六銀が支えていても、相手に具体的な攻めがあれば、
局面全体の教師評価はそちらで決まる。その誤差だけでは望む棋風を十分に評価できない。

同じエンジンを教師にすることが無意味なのではない。
深く読んで初めて分かる価値を浅い評価にも覚えさせる余地はある。
今回の単純な特徴と少量のデータで、その価値を取り出せるかは未確認。
[位取りの具体例](gold-silver/2026-10-12-supported-pawn-learning-result.md)を参照。

### 独立した材料の少なさ

- 模倣の転移実験は実質4組で学習し4組で確認。学習係数は5,391個。
  係数数だけで過学習と断定はできないが、別の指し方への通用を判断する材料は極めて少ない。
- 勝敗学習は拡大後も256局面に対し40,052係数。元の棋譜2,740局と、実際に更新へ
  用いた情報量は違う。初回模倣では7,190係数のうち4,801個が1組だけに出現した。
- 金の前進では当初143／35件に五段目以降の対象金がなかった。補充は不足に対応した
  妥当な改善だったが、深い盛り上がりの例は依然少数。
- 検証集合の繰り返し利用、一部test棋譜の閲覧、過去runtimeの不明点がある。
  記録は正直だが、未見局面での効果を確定する役割には限界がある。

### 途中の形と最終勝敗の距離

25手目の▲５七銀・▲５六歩の形に、209手目の投了だけを根拠に減点を教えると、
その形と後の指し間違いを区別できない。一方、後手62手目の△６二玉・△７二金に対し、
▲７四歩と金打ちが迫る例では、局面の危険と敗戦の結び付きが比較的見える。
この二種類が同じ「負け0」で学習される。

勝敗を途中局面の教師にすること自体が誤りではない。
多数の異なる展開があれば、同じような形から勝つ場合・負ける場合を通じて傾向を学べる。
今回はその平均を取る材料が少ないという制約である。

| 確認できた事実 | 考えられる仮説（未確定） |
| --- | --- |
| 検証の負け局面の誤差悪化が初回・拡大・重み付けで残った | 勝ち局面の共通配置への加点が、危険な局面にも伝わる可能性 |
| 診断した4局面では加点の大半がPP由来 | 玉への攻めなど、配置の文脈を十分区別できていない可能性 |
| 学習側では勝ち・負け両方の平均誤差が改善 | 単純な勝敗符号の逆転より、別棋譜への一般化が主な問題である可能性 |
| 進行度重み付け後も傾向が残った | 進行度だけでは敗因との距離や配置の危険を表せない可能性 |

4局面は診断用に選んだ例で代表標本ではない。どの仮説も原因として確定していない。
敗戦ラベルへの誤差悪化と、実戦で負けやすくなることは別である。

## 安全のための条件が、有用性の判断を難しくしたか

難しくしている。ただし実験ごとに事情が違う。

玉安全度は5更新付近からほぼ落ち着き、20更新ではデータからの更新方向と、
変更を小さく戻す正則化がほぼ釣り合った。係数上限にも達していない。
ここは「もっと回せばよかった」とは言えない。
[保存結果の診断](king-safety/2026-10-11-king-safety-saved-result-diagnosis.md)が直接の根拠。

模倣・勝敗学習は1更新の最大幅0.001cp、20更新、途中の係数を平均して保存する設定。
実際の局面差は主に1〜3cp。模倣例では実戦手と代替手に数百cpの差があるのに、
数cpしか近づいていない。これでは、その構想を選ぶようになったかを測りにくい。
係数上限を引き上げるだけで解決する証拠はなく、更新数・幅・平均化も含む設計の問題。
[更新器](../../../tools/learning/imitation/sparse_updater.py)と
[初回模倣結果](data/2026-10-12-historical-imitation-first-result.md)を参照。

逆に小さな静的差でも探索結果は大きく変わる。
△８二玉から△５二金への切替は、二手を同時比較すると現行評価でも△５二金が上位だった。
少数の最善手変更だけを成果と数えるのも適切ではない。
[二手比較](data/2026-10-13-outcome-king-gold-content-check.md)を参照。

今後は次を分ける。

- 維持する安全策：運用ファイルの隔離、入力・出力の保存、符号・丸めの検証、独立した最終評価。
- 目的に合わせて設計し直す条件：更新数、更新幅、正則化、局面数、候補の比較方法。

「20回だけ」「係数をほぼ動かさない」は運用保護の必須条件ではない。
旧実験のmarkerを解除・迂回する必要はないが、新しい実験まで同じ条件に縛る必要もない。
将来は学習側で十分に適合できるかと、別棋譜で役立つかを段階的に確認する。
条件を強めれば有効になると保証する提案ではない。

## 厚みの個性と棋力の評価を分ける

個性として知りたいのは、例えば次の行動である。

- ▲６五歩の足場を銀で支え、次の金の進出につなげる。
- 銀が前進しても、後方の金で取り返せる関係を残す。
- 金銀が働く場所に玉を近づけるが、支え役を歩で攻められるときは無理をしない。

金銀の高さや連結数が増えただけでは足りない。
必要な場所で働く、交換後も支えが残る、危険なら構想を中断するところまで、
指し手と短い継続で見る必要がある。
[前線の金銀の比較](gold-silver/2026-10-12-front-gold-silver-control-review.md)に反例がある。

棋力側では同条件・同じ出発局面で、先後を入れ替えた対局比較が必要。
勝率だけでなく、負けの増加、持ちこたえられた局面、無理な前進による崩れも確認する。
少数対局を小さな強化の証明にはしない。

「棋力向上は未確認だが、許容できる成績の範囲で好みの指し方が増えた」という
採用理由は成立する。ただし現在は、その個性の変化も許容範囲内の成績も十分に測れていない。
許容する成績差はユーザーと決める事項で、ここでは数値を設定していない。
小さな誤差改善で代用するべきではない。

## 次の案の比較：探索評価と勝敗の混合を含む

まず厚みの行動評価を整え、その後に棋力向けの教師を見直すことを勧める。
探索評価と勝敗の混合は、棋力向け学習の第一候補。

| 案 | 将棋での狙い | 優先度・判断 |
| --- | --- | --- |
| 厚みを選ぶ／控える局面の対比較 | 盛り上がるべき時と、支えが崩れるので控える時を区別 | 最優先。個性の目標を直接測る |
| 探索評価＋勝敗 | その場の形勢と実戦の結末の両方から学ぶ | 棋力学習の第一候補。探索だけ・勝敗だけと比較 |
| 独立した棋譜・局面の追加 | 同じ形が違う相手・展開で働くかを学ぶ | 高い。ただし目的と検証方法を決めてから |
| 進行度重みの再調整 | 序盤の形に最終敗戦の責任を負わせすぎない | 低い。細かな調整を続ける根拠は弱い |
| 投了までの距離による重み付け | 結末に近い局面を重くする | 保留。敗因や粘る力そのものを表すわけではない |
| 同じ2局の模倣を強める | 本家の手に近づける | 保留。構想とその局特有の手・失敗を区別しにくい |
| モデル・特徴の大型化 | 複雑な厚みを表現する | 後回し。データと評価設計の制約が先 |

混合の意味は、後で負けてもこの時点では十分戦えるという探索判断を残しつつ、
似た形から実際には負けが多いという結果も取り込むこと。
進行度重み付けは敗戦を教える強さを変えるだけだが、混合は教える内容も変える。

ただし混ぜれば強くなるわけではない。現行エンジンの見落としを引き継ぐ可能性があり、
混合比を調整して同じ検証集合に合わせ込むこともできてしまう。
将来比較するなら同じデータ・更新予算で、探索だけ／勝敗だけ／事前に決めた混合を比べる。
過去探索のruntimeは不明なので、その値を現行教師と同一視しない。
現行条件の教師を使うなら生成費用も計画に含める。

既存の探索教師の学習は静止探索末端、勝敗学習は元局面を使う。
混合では両者をどの局面の評価に教えるかを先に揃える必要がある。
単に既存の損失二つを足すだけで同じ意味になるとは限らず、混合比と尺度も未決定。
勝敗層を均等に抽出した集合での sigmoid(cp/600) を、自然な実戦勝率と解釈しない。

厚みの個性はこの混合だけでは保証されない。
個性を教える指し手の対比較と、形勢を教える学習を別の評価軸として持つ。
[進行度計画の比較](data/2026-10-14-outcome-stage-weighting-plan.md)も参照。

## 続ける・やめる・保留すること（優先順）

1. **続ける：厚みが働いた例と崩れた例の整理を、行動評価につなげる。**
   同じ形の数え上げから、実際にどちらの手を選ぶかへ進める。
2. **続ける：実験を隔離したまま、効果を観測できる更新規模を設計する。**
   学習側への適合、別棋譜への通用、探索・対局の順に判断する。
3. **続ける：棋力向けには探索評価と勝敗の混合を比較候補にする。**
   負け棋譜も残し、教師と局面の対応を見直す。
4. **やめる：同じ小幅20更新を繰り返し、微小な誤差差だけでテーマの有望さを決めること。**
   データ量だけを増やして同じ判断を繰り返す優先度も低い。
5. **やめる：厚みの個数、候補自身の探索評価上昇、少数の最善手変更を成果として代用すること。**
6. **保留：既存候補の採用、2局だけの模倣の増幅、進行度式の細かな調整、大型の評価構造変更。**

現行評価の維持は妥当。既存の実験を失敗と断定せず、実装・計数・記録の成果を活用する。
Solへの引き継ぎではこの優先順位を出発点に、次の具体的な実験範囲と成功条件を検討する。
この保存依頼では追加実験を行わず、終了済み実験・候補・運用データを維持した。
