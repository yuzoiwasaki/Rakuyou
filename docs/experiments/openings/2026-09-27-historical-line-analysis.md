# 本家系の銀盛り上がり構想 重点解析

## 目的

2011年公開プレマッチと2012年第1回電王戦に共通する
`△5四歩・△4二銀・△5三銀`を出発点に、歴史的手順を現代のRakuyouで評価し、
改善した本家系の定跡骨格を探す。

## 歴史的2局の共通局面

2局は4手目と6手目の順序が異なるが、次の8手で同一局面へ合流する。

```text
▲7六歩 △6二玉 ▲6八飛 △5四歩
▲3八銀 △4二銀 ▲4八玉 △5三銀
```

その後も両局は次の手順で共通する。

```text
▲3九玉 △6四歩 ▲6六歩 △7二銀
```

13手目に、本番の`▲6五歩`と公開プレマッチの`▲9六歩`へ分岐する。

## 解析条件

| 項目 | 値 |
|---|---|
| 深さ | 24 |
| MultiPV | 3または5 |
| スレッド | 1 |
| ハッシュ | 512 MB |
| 定跡 | 無効 |
| Ponder | 無効 |

新米長玉側の手を選ぶ局面では`ShinYonenagaGyoku=true`、相手の主要応手を選ぶ
局面では通常側として`false`を使用した。異なる設定や局面の評価値は直接比較せず、
各局面内の候補手比較に使う。

## 歴史的な`△6四歩`の検証

`▲3九玉`に対し、歴史的2局で指された`△6四歩`を強制探索した。

| 候補 | 評価値 |
|---|---:|
| `△7二銀` | -169 |
| `△8四歩` | -169 |
| `△6四歩`（強制） | -265 |

`△6四歩`は現代の上位候補より約96点低かった。本家の構想全体ではなく、
この歩を急ぐ手順に改善余地がある。

ただし、`△6四歩 ▲6六歩 △7二銀`まで進んだ後の歴史的な応戦は支持された。

- 本番の`▲6五歩`には、実戦どおり`△同歩`が-194で首位。次点の`△6三銀`は
  -327で、133点差だった。
- 公開プレマッチの`▲9六歩`には、実戦の`△6三銀`が-253で、首位の`△7一玉`
  -248と5点差だった。

本家の応戦は筋が通っているが、`△6四歩`を指す時期を遅らせる余地がある。

## 現代化した本家系

`△6四歩`を急がず、次の順序へ組み替えた。

```text
▲7六歩 △6二玉 ▲6八飛 △5四歩
▲3八銀 △4二銀 ▲4八玉 △5三銀
▲3九玉 △7二銀 ▲6六歩
```

後手の候補は次の通り。

| 候補手 | 評価値 |
|---|---:|
| `△7一玉` | -200 |
| `△8四歩` | -205 |
| `△6四歩` | -257 |
| `△7四歩` | -257 |

`△7一玉`を加えた後、通常側の主要応手は次のようになった。

| 順位 | 先手の候補 | 通常側評価 |
|---:|---|---:|
| 1 | `▲6五歩` | +204 |
| 2 | `▲7八銀` | +180 |
| 3 | `▲5八金左` | +178 |
| 4 | `▲7七角` | +169 |
| 5 | `▲9六歩` | +137 |

`△8四歩`を先に指した場合も、通常側の首位は`▲6五歩`だった。

| 順位 | 先手の候補 | 通常側評価 |
|---:|---|---:|
| 1 | `▲6五歩` | +195 |
| 2 | `▲7八銀` | +192 |
| 3 | `▲5八金左` | +178 |
| 4 | `▲7七角` | +177 |
| 5 | `▲9六歩` | +138 |

どちらの待ち方でも、先手は右側の囲いを進めるより`▲6五歩`で左辺・中央から
動く手を最有力とした。新米長玉に都合のよい`▲3九玉`以降だけを前提にせず、
早い仕掛けを主分岐として扱う必要がある。

### 早い`▲6五歩`への応答

`△7一玉 ▲6五歩`に対しては`△8四歩`が-181で明確な首位だった。読み筋は
`△8四歩 ▲7八銀 △8三銀 ... △6二飛 ... △8二玉`と進んだ。

`△8四歩 ▲6五歩`に対しては`△8三銀`が-192、`△7一玉`が-197でほぼ並んだ。
したがって、`△7一玉`と`△8四歩`のどちらを先にしても、もう一方と
`△8三銀`へ進む構想に合流できる。

`△7一玉`は歴史的な`6二→7二→8三`とは異なるが、銀が7二にいるため
`△7二玉`とはできない。この局面では`6二→7一→8二`と進む、銀を避けた
現代的な上昇経路になっている。読み筋に`△8二玉`が現れるため、玉を上に出す
構想自体を捨てた手ではない。

### 静かな応手と手順前後

`△7一玉`と`△8四歩`の後、`▲7八銀`、`▲5八金左`、`▲7七角`、
`▲9六歩`への応答をそれぞれ直接解析した。

| 先手の応手 | `△7一玉`を先にした場合 | `△8四歩`を先にした場合 |
|---|---|---|
| `▲7八銀` | `△8四歩` -177 | `△2四歩` -190、`△7一玉` -213 |
| `▲5八金左` | `△8四歩` -192 | `△7一玉` -213、`△8三銀` -213 |
| `▲7七角` | `△7四歩` -163 | `△8三銀` -174、`△7一玉` -174 |
| `▲9六歩` | `△8四歩` -151 | `△7一玉` -143 |

多くの枝は`△7一玉・△8四歩・△8三銀`の形へ合流した。`▲7八銀`に
`△8四歩`を先にした枝では`△2四歩`が首位になったため、完全な手順前後では
ないが、`△7一玉`も候補に残った。

### `△8二玉`以降

早い`▲6五歩`への主読み筋を、次の`△8二玉`まで進めた。

```text
... △7一玉 ▲6五歩 △8四歩 ▲7八銀 △8三銀
▲6七銀 △3四歩 ▲6六銀 △2四歩 ▲7七角 △6二飛
▲5八金左 △7二金 ▲4六歩 △2五歩 ▲3六歩 △8二玉
```

この局面の通常側第1候補は`▲4七金`+111だった。その後の新米長玉側は
`△4二飛`が-94で首位だった。玉をさらに上げる手よりも、8二の玉と8三の銀を
保ちながら飛車を四間へ回す構想が選ばれた。

この配置では8三を銀が占めるため、本家と同じ`△8三玉`へ直ちに進むことは
できない。本家の`6二→7二→8三`をそのまま再現する形ではなく、
`6二→7一→8二`で玉を止め、銀を8三へ上げる現代化した配置と見るのが自然である。

## 囲い前の早い左辺整備

本家の4手目`△5四歩`の直後から、通常側が右側の囲いを後回しにする可能性も
調べた。

```text
▲7六歩 △6二玉 ▲6八飛 △5四歩
```

| 順位 | 先手の候補 | 通常側評価 |
|---:|---|---:|
| 1 | `▲6六歩` | +190 |
| 2 | `▲7八銀` | +186 |
| 3 | `▲3八銀` | +186 |
| 4 | `▲5八金左` | +186 |
| 5 | `▲4八玉` | +183 |
| 6 | `▲1六歩` | +175 |
| 7 | `▲7七角` | +171 |
| 8 | `▲4六歩` | +166 |

`▲6六歩`が首位で、歴史的な`▲3八銀`や`▲4八玉`より先に左辺を整える順は
十分に有力だった。ただし読み筋では直ちに`▲6五歩`とはせず、駒組みを進めて
から突いている。

この`▲6六歩`に対する新米長玉側の首位は、歴史的な`△4二銀`-191だった。
`△8四歩`-196、`△7二銀`-208を上回り、本家の銀上がりは
相手が囲いを急がない場合にも成立している。

4手目を`△4二銀`と入れ替えた場合、先手上位は`▲4八玉`、`▲6六歩`、
`▲3八銀`、`▲7八銀`がいずれも+199だった。その後の`▲6六歩`には
`△8四歩`と`△7二銀`が-189、`△5四歩`は-195だった。
こちらも成立するが、`△5四歩 ▲6六歩 △4二銀`は相手の積極策に対して
歴史的な手順を自然に継続できる。

## 現時点の定跡骨格候補

```text
▲7六歩 △6二玉 ▲6八飛 △5四歩
▲3八銀 △4二銀 ▲4八玉 △5三銀
▲3九玉 △7二銀 ▲6六歩 △7一玉
```

歴史的な銀の盛り上がりを保ちつつ、約96点低かった早い`△6四歩`を後回しにした。
先手が囲いを急がず早く`▲6六歩`や`▲6五歩`と動いても、本家の`△4二銀`と
現代化した`△8四歩・△8三銀`が有力だった。静かな応手にも多くの枝で同じ形へ
合流し、玉は8二、銀は8三に置く構想まで確認できた。完全な一本道ではないため、
実際の定跡では相手の応手ごとに`△7一玉`と`△8四歩`の順序を選ぶ。
