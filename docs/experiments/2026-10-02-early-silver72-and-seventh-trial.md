# △５四歩骨格の早い△７二銀と、７四歩型の試験定跡

## 結論

「2」の**△７二銀を早める入口は支持されたが、▲６五歩への△７四歩は支持が弱かった**。したがって今回は「1」の端歩ルートをベースに、独立した小さい実験定跡を作成した。正式版への採用や棋力向上は主張しない。

ユーザーは「１か２のどちらかをベースに、ダメ元でも７四歩型を一度試したい」と希望した。このため、最善候補ではない準備手も、評価差と目的を記録して試験用に含めた。v1・v2は一切変更していない。長い対局はユーザーがCodex外で実行する。

| 比較 | 1：端歩待機 | 2：△５四歩・早い△７二銀 |
|---|---|---|
| △７四歩直前 | ▲７七角がある３局面で深さ28の首位または１cp差 | ▲６五歩直後では深さ28の上位５手外 |
| 準備の課題 | 元第81局の△７二銀は40cp差。ただし今回の別順序では準備手の差を小さくできた | 早い△７二銀自体は深さ28で首位 |
| 相手依存 | 角上がりを保留されたら探索へ戻す | ▲６五歩は通常側の深さ24で５位。標準定跡のプローブでも別手だった |
| 今回の扱い | 条件付きの構想試験を作成 | △７四歩の主入口には採用しない。今後の副案として保存 |

## 解析条件・完全性

- 基準コミット：`07defdd`（解析開始時のローカルHEAD）。エンジンの再ビルドはしていない。
- バイナリSHA-256：`a1a5e25ada0d7be1375b45168586f00f7feaa29f1a87074a85b0e4b09c571f1b`。
- １スレッド、512 MB、OwnBook/Ponder無効、全て新規プロセス。後手は `ShinYonenagaGyoku=on`、通常側はoff。
- 「2」は８種類の局面へ11回の解析（深さ24・５候補が８回、深さ28・５候補が２回、深さ28・限定３候補が１回）。
- 実験定跡の準備として「1」に６局面の深さ24・５候補解析を追加した。合計14種類・17回、深さ24が14回、深さ28が３回。
- 全候補が要求深さに到達、打ち切りなし、bound表示なし、首位PVとbestmoveが一致。今回の７結果ファイルのエラー記録は全て０。
- 新しい解析入力と13定跡局面の定跡手まで、30手順・計308手を実行ファイルの `legalmoves` と照合した。定跡に記録した根拠の局面・候補手・明記した順位や評価差も保存データと一致した。

評価は解析局面の手番側のcp値。後手には既存の25cp補正がある。別局面・別設定・限定探索と無制限探索の評価差を、そのまま一手の損失や棋力差としない。

| △５三銀（既存定跡） | 1位 −191 | 2位 −207 |

△７二銀と△５三銀は２cp差で順位が逆転した。△７二銀の準備は十分に試せる候補だが、最善の順序を確定したとは扱わない。

△７二銀に対する通常側の深さ24は、▲６六歩+193、▲５八金左+192、▲９六歩+181、▲３九玉+181、▲７八銀+173。元棋譜の▲６六歩は支持された。

▲６六歩への後手は、△５三銀−188、△７一玉−190、△１四歩−191、△８四歩−194。元棋譜の△５三銀も上位に残る。

一方、その後の通常側は▲９六歩+182、▲７八銀+175、▲３九玉+173、▲５八金左+171、▲６五歩+166だった。元棋譜の▲６五歩は有力候補だが、最も厳しい応手ではない。

通常側の標準定跡を有効にした１回ずつのプローブでは、△７二銀後は▲３九玉、▲６六歩△５三銀後は▲７八銀が `book` として選ばれた。これは確率分布や実戦頻度の測定ではないが、保存棋譜どおりに進む保証がないことを示す。

## 2の本題：▲６五歩へ△７四歩

```text
▲７六歩 △６二玉 ▲６八飛 △５四歩
▲３八銀 △４二銀 ▲４八玉 △７二銀
▲６六歩 △５三銀 ▲６五歩
```

深さ24は△７一玉と△８四歩が−168で首位同点、△１四歩−178。△７四歩は上位５手外だった。

深さ28も△８四歩−162、△７一玉−170、△１四歩−238、△５二玉−246、△４四歩−263となり、△７四歩は上位５手外のままだった。

△７四歩の評価を確認するため、**候補を△７四歩・△７一玉・△８四歩の３手だけに限定した**深さ28・MultiPV３を別実行した。

| 限定探索内の候補 | 評価 |
|---|---:|
| △８四歩 | −184 |
| △７一玉 | −195 |
| △７四歩 | −239 |

同じ限定探索内で△７四歩は首位から55cp下。無制限探索の△８四歩−162と引き算して「77cp損」とはしない。いずれの検証も、ここで△７四歩へ固定する支持は弱い。

△７四歩を指した後の通常側は▲５八金左+260が首位、▲３九玉+244、元棋譜の▲７八銀+204が続いた。後手の直接応答は次の通り。

| 先手の応手 | 後手首位 | △７三銀 |
|---|---|---|
| ▲５八金左（通常側首位） | △７一玉 −218 | 2位 −248（30cp差） |
| ▲７八銀（元棋譜） | △７三銀 −164 | 1位 |

銀を上げる到達局面だけを見ると魅力的でも、相手が強い別手を選ぶと順序と評価が変わる。「▲６五歩なら必ず△７四歩～△７三銀」とは登録しない。

## 1をベースにした試験用の準備手順

[1の解析](2026-10-02-edge-wait-seventh-file-analysis.md)では元第81局の△７二銀直前が深さ28で40cp差だった。今回はその一手を固定する入口を避け、△７二銀を先にする別順序を追加確認した。

| 後手の入力局面・候補 | 深さ24の結果 | 首位との差 |
|---|---|---:|
| △１四歩▲６六歩への△７二銀 | 3位 −202（首位△１五歩 −189） | 13 |
| △１四歩▲４八玉△１五歩▲６六歩への△７二銀 | 1位 −203 | 0 |
| △７二銀▲７八銀への△１五歩 | 5位 −199（首位△８四歩・△５四歩 −178） | 21 |
| 続く▲４八玉への△７一玉 | 首位同点 −202 | 0 |
| 続く▲３八銀への△３四歩 | 1位 −190 | 0 |
| 続く▲５八金左への△２四歩 | 1位 −194 | 0 |

構想のために13cp差の△７二銀と21cp差の△１五歩を選ぶ。異なる局面の差を合計して「34cp損」とはしない。これらの準備手は深さ24の確認であり、深さ28以上の最善手保証ではない。

代表手順は標準定跡版第63局の形へ向かう。

```text
▲７六歩 △６二玉 ▲６八飛 △１四歩
▲６六歩 △７二銀 ▲７八銀 △１五歩
▲４八玉 △７一玉 ▲３八銀 △３四歩
▲５八金左 △２四歩 ▲７七角 △７四歩
▲６五歩 △７三銀
```

先手の手は対局相手が選ぶ。▲１六歩や、別の玉・銀・角の動きには未登録の局面で探索へ戻る。角上がりを保留されたら△７四歩を自動的に指さない。主筋とは異なる第81局・第43局の既検証局面にも、到達時だけ△７四歩を使う条件付きエントリを残した。
