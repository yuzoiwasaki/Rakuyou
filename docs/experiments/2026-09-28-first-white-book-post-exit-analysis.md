# 後手第一版専用定跡・定跡出口の勝敗と候補手

## 対象と読み方

[第一版の100局](2026-09-28-shin-dedicated-white-book-v1-vs-normal-depth15.md)のうち、後手新米長玉の50局を調べた。対局は深さ15で、通常側は標準定跡あり。以下の直接解析は定跡なし・Ponderなし・１スレッド・Hash 512 MBで、通常側は `ShinYonenagaGyoku=false`、後手側は `true` とした。深さ24・28のMultiPVを使い、合流点では候補数を12まで広げ、最後に３手だけを強制比較した。

解析値は**その局面の手番側から見た点数**。評価差は同じ局面・同じ解析実行の候補手の間だけで比較する。手番や深さ、MultiPV数が違う点数を直接引き算しない。実戦の勝敗は相手の手も中盤以降の探索も含むため、序盤の一手の優劣を証明しない。

共通の定跡手順は次の通り。

> ▲７六歩 △６二玉 ▲６八飛 △５四歩
> ▲３八銀 △４二銀 ▲４八玉 △５三銀
> ▲３九玉 △７二銀 ▲６六歩 △７一玉
> ▲７八銀 △８四歩

△３四歩後に残りの▲５八金左／▲６七銀が指されると、先手の手順が違っても同一局面へ合流する。該当21局は後手５勝13敗３分。次の後手手は△８三銀が20局、△１四歩が１局だった。△８三銀の20局は５勝12敗３分で、直後の先手手は▲４六歩・▲９六歩が各５局、▲６五歩が４局など。後述する深い解析で首位となる▲７五歩は、深さ15の実戦には現れなかった。合流点の成績は全後手50局の得点率と大きく違わず、合流や△８三銀だけを敗因とは言えない。

深さ15の後手側探索評価は、勝局も負局も定跡を抜けた直後には約−200点だった。勝局13局の16手目中央値は−201点、負局30局は−190.5点で、入口の点数は重なっている。40手目には勝局13局のうち10局がまだ負評価。60手目の中央値は勝局−117点・負局−280点、80手目は勝局＋225点・負局−450.5点へ分かれた。ただし負局でも途中で正評価になる局があり、単一の「負け確定手」をこの経過から特定できない。

勝ちの代表例は pair 18 / game 2。▲６七銀後に△１四歩を指し、後手評価は16手目−210点から80手目＋233点へ変わり、111手で勝った。pair 11 / game 2 は▲５八金左後の△３四歩で、16手目−177点、80手目＋859点、133手で勝った。負けの代表例 pair 19 / game 2 も16手目は−208点だったが、80手目−982点となり100手で負けた。３局だけの「▲６七銀後△１四歩が全勝」や、別局面の「▲５八金左後△１四歩が４局で０勝」を定跡採用・除外の根拠にはしない。勝局の多くは序盤からの押し切りではなく、中盤での持ち直しだった。

## 21局が合流した局面

次の二つの手順は同じ盤面・持ち駒・手番になる。

1. ▲７八銀 △８四歩 ▲６七銀 △３四歩 ▲５八金左
2. ▲７八銀 △８四歩 ▲５八金左 △３四歩 ▲６七銀

いずれも上記の共通手順の12手目までを前提とする。深さ24・MultiPV５では△２四歩−264、△１四歩−266、△５二金右−268、△４四歩−274、△３五歩−338で、実戦の△８三銀は上位５手に入らなかった。ただし同じ深さでもMultiPVを12に広げると、△２四歩−247が首位、△８三銀−274が４位・27点差となった。候補数で探索木が変わるため、５候補の順位表と12候補の評価値を混ぜない。

深さ28で**△２四歩・△８三銀・△５二金右の３手だけ**を強制比較すると、△５二金右−250、△２四歩−257（７点差）、△８三銀−288（38点差）。この解析は３手の相対比較であり、△５二金右が全合法手の最善と証明したものではない。△５二金右の読み筋は「△５二金右 ▲６五歩 △４四歩 ▲４六歩」、△８三銀は「△８三銀 ▲７五歩 △２四歩 ▲７六銀」。実戦で20局選ばれた△８三銀は、深さ24・MultiPV12では首位から27点、深さ28の３手比較では38点低かったため、専用定跡を延ばす前に再検討する価値がある。

通常側を定跡なしで深さ24・MultiPV５で直接解析すると、△８三銀後の首位は▲７五歩＋298で、次点の▲９六歩＋242より56点上。主な読み筋は「▲７五歩 △３五歩 ▲８六歩 △３二飛」。実戦の深さ15では▲７五歩が一度も指されていないので、これは今回の敗局を直接説明するものではなく、より強い応手への耐性を示す。△５二金右後の通常側首位は▲９六歩＋278、次点▲６五歩＋267。異なる局面の＋298と＋278を引き算して後手の手を比較しない。

## 判断と次の確認

第一版の△８四歩そのものを負け筋とする根拠は見つからなかった。後手は定跡を抜けた直後から約−200点で、勝局もここから中盤に持ち直している。頻度の高い出口では、▲６七銀／▲５八金左に対する△１四歩が深さ28で首位になったが、深さ24とは順位が違い、▲５八金左後の△８三銀とは３点差。ここでは候補を保留する。

改善の手掛かりとして具体的なのは、二つの手順から合流する21局の後手手番。実戦で20局選ばれた△８三銀と、△２四歩・△５二金右を比較する価値がある。ただし深さ28の比較は３手限定なので、全候補のMultiPVと、通常側の▲７五歩など厳しい応手を確認してから採用を決める。候補JSON・エンジン用定跡は今回変更しない。勝ちパターンは単一の定跡延長ではなく、後手が序盤の不利評価を中盤で覆した複数の展開として追う。
