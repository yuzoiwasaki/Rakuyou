# オリジナル7筋構想 重点解析

## 目的

後手新米長玉の独自候補である`△7二銀・△7四歩・△7三銀`を、通常Rakuyouの
先手四間飛車に対して検証する。`△7四歩`を成立させる条件、先手の主要応手、
玉と飛車の配置、早い`▲6五歩`への耐久性を調べる。

## 解析条件

| 項目 | 値 |
|---|---|
| 深さ | 24 |
| MultiPV | 5または8 |
| スレッド | 1 |
| ハッシュ | 512 MB |
| 定跡 | 無効 |
| Ponder | 無効 |

新米長玉側の応手には`ShinYonenagaGyoku=true`、通常側の先手応手には`false`を
使用した。評価値は各局面の手番側から見た値であり、異なる局面間では探索条件や
手数が違うため、差をそのまま強さの差とはみなさない。

実戦上の理由は弱い。この手を前提にした手順は主作戦にせず、局面が現れた場合の
機会的な分岐として扱う。

## 玉と銀の手順前後

通常側第1候補の`▲4八玉`に対し、次の2局面を比較した。

```text
A: ... △7四歩 ▲4八玉 △7一玉
B: ... △7四歩 ▲4八玉 △7三銀
```

Aの読み筋では多くの枝で後に`△7三銀`へ進んだ。Bでは通常側の第1候補
`▲4六歩`に`△7一玉`が-104で明確な首位となった。代表的な骨格は次になる。

```text
▲7六歩 △6二玉 ▲6八飛 △7二銀
▲7七角 △7四歩 ▲4八玉 △7三銀
▲4六歩 △7一玉
```

玉と銀の順序には柔軟性があるが、この代表枝では銀を7三へ上げてから玉を7一へ
寄る順が明快だった。

単一の飛車位置へ固定せず、先手の角・銀・6筋の形に応じて振り直す構想になる。

## 早い`▲6五歩`への対応

`▲6六歩`に`△3二飛`とした後、読み筋どおり`▲6五歩`を進めた。

```text
... △7三銀 ▲4六歩 △7一玉
▲6六歩 △3二飛 ▲6五歩
```

新米長玉側の上位4手は`△2四歩`、`△5二金右`、`△3四歩`、`△7二金`で、
すべて-76だった。仕掛け前の`△3二飛`-77とほぼ同じ水準を保ち、早い6筋攻めで
直ちに崩れる結果にはならなかった。

## `△8四歩`で`▲7七角`を促す案

先手が自発的に`▲7七角`と上がる理由が弱いため、自然な先手の駒組みに
`△8四歩`を合わせ、飛車先を受ける意味を作った。

```text
▲7六歩 △6二玉 ▲6八飛 △7二銀
（先手の駒組み）△8四歩
```

先手の最初の手を`▲4六歩`、`▲3八銀`、`▲5八金左`、`▲4八玉`、
`▲6六歩`とした5局面すべてで、次の`▲7七角`は上位6手以内に入った。
首位同値または首位から4〜16点差となり、`△8四歩`によって角上がりは
実戦的な選択肢になった。

しかし、実際に`▲7七角`と上がった後の新米長玉側は、7筋より8筋を優先した。

- `△8三銀`は3局面で首位または同点首位、残る局面でも上位に入った。
- `△7四歩`は`▲5八金左`の枝で7位、`▲4八玉`の枝で8位だった。
- 残る3局面では`△7四歩`は上位8手に入らなかった。

`△8四歩`は`▲7七角`を自然にするが、同時に銀を8三へ上げる方が自然になる。
したがって、7筋構想を準備する手としては目的が競合する。

## `△7二飛`のタイミング

`△7四歩・△7三銀`まで組めた後、空いた7二へ飛車を回す攻撃構想を直接調べた。
代表骨格に対する先手の上位5応手の直後で`△7二飛`を強制した。

| 先手の応手 | 強制`△7二飛` | その局面の最善評価 | 差 |
|---|---:|---:|---:|
| `▲3八銀` | -228 | -75 | 153 |
| `▲5八金左` | -225 | -93 | 132 |
| `▲7八銀` | -231 | -65 | 166 |
| `▲8六角` | -732 | -98 | 634 |
| `▲6六歩` | -231 | -77 | 154 |

骨格完成直後に飛車を7二へ回る手は早かった。特に`▲8六角`がいる局面では、
`△7二飛 ▲5三角成`を許して大きく評価を落とす。

一方、自己対局の勝ち局では先手が`▲7五歩`と7筋へ働きかけた直後に
`△7二飛`と回っていた。その局面を同じ深さで再解析した。

```text
... △7四歩 ▲6五歩 △7三銀 ▲6七銀
△7一玉 ▲6六銀 △2五歩 ▲7五歩
```

| 順位 | 後手の候補 | 評価 |
|---:|---|---:|
| 1 | `△7二飛` | -136 |
| 2 | `△5二金右` | -160 |
| 3 | `△3三角` | -189 |
| 4 | `△6二金` | -198 |
| 5 | `△6二飛` | -237 |

このタイミングでは`△7二飛`が単独首位で、次点より24点よかった。読み筋は
`△7二飛 ▲7四歩 △同銀`と進み、先手の7筋の歩を取り返している。
したがって`△7二飛`は先に攻めを作る手ではなく、先手の`▲7五歩`に合わせて
7筋の反撃と受けを兼ねる手として有力である。

## `△7一玉`で待つ案

飛車先を伸ばさず、`△7一玉`で先手にもう一手自然な駒組みをさせる案も調べた。
先手の最初の手を同じ5候補とし、その後の通常側の主要応手を選んだ。

代表例は次のような局面である。

```text
▲7六歩 △6二玉 ▲6八飛 △7二銀
▲4六歩 △7一玉 ▲3八銀
```

ほかに`▲3八銀 ... ▲7八銀`、`▲5八金左 ... ▲4八玉`、
`▲4八玉 ... ▲7八銀`、`▲6六歩 ... ▲4八玉`も調べた。5局面すべてで
`△7四歩`は上位8手に入らなかった。上位は`△8四歩`、`△5四歩`、
`△4二銀`などで、自然な駒組みを一手待つだけでは7筋の歩を突く理由は
生まれなかった。

## 結論

- `△7二銀`自体は柔軟だが、直後の`△7四歩`は早い。
- `▲7七角`を待ってからの`△7四歩`は首位と15点差に入り、その後の主要応手
  すべてで`△7三銀`構想へ接続した。
- ただし、後手が飛車先を伸ばしていない形で先手の`▲7七角`を期待するのは
  実戦的ではない。この枝は主定跡ではなく、局面が現れた場合の候補に留める。
- `△8四歩`で`▲7七角`を促すことはできるが、その形では`△8三銀`が優先され、
  `△7四歩`は主候補にならなかった。
- `△7一玉`で先手の自然な駒組みを一手待っても、調べた5局面すべてで
  `△7四歩`は上位8手に入らなかった。
- `△7二飛`を骨格完成直後に急ぐと大きく評価を落とすが、先手の`▲7五歩`直後
  には単独首位となった。7筋を先攻する手ではなく、反撃のタイミングで使う。
- `△7三銀`と`△7一玉`には手順前後がある。代表枝では銀を先にする順が明快。
- 骨格完成後は`△3二飛`、`△4二飛`、`△5二飛`を先手の形に応じて使い分ける。
- `▲6六歩・▲6五歩`の早い攻めにも評価を維持した。
- 次の骨格は成立した場合の有力候補として残すが、現時点では自然な先手の
  駒組みからこの形を主系として成立させる手順は見つからなかった。

```text
▲7六歩 △6二玉 ▲6八飛 △7二銀
▲7七角 △7四歩 ▲4八玉 △7三銀
▲4六歩 △7一玉
```

この手順を定跡へ入れる場合は、`▲7七角`が実際に指された分岐だけに限定し、
`△7三銀`と`△7一玉`の順序、飛車の振り場所を分岐として保持する。
