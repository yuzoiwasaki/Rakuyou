# 有力候補の再確認（未採用）

定跡PR2とは独立し、`851dc0f`（origin/main）から開始した探索実験。
評価・定跡・初手の規則は変更しない。長時間対局とmainへのマージは未実施。

## 試作

ルートで最初の候補以外を検索した後、実現確率0.25以上、返った評価が
現在のalpha以下かつ128以内、深さ8以上なら、alphaを128下げたPV探索で再確認する。
詰み近傍を除外し、一回のルート探索呼び出しにつき最大1候補。
反復深化やaspirationの再探索では再び発動し得るため、1着手につき1回ではない。
深さ延長や特定の駒・升・戦型への加点はない。

確率や窓の閾値は試作条件であり、最適値を主張しない。
fail-lowの値は厳密な評価ではなく上界なので、128以内という条件も
真の評価差が小さいことを保証しない。追加のPV探索でも枝刈りは残る。

## 再現

元版のbin/matchを保持し、試作は別名でビルドする。

```sh
make TARGET=match output_file=bin/match-root-recheck executable -j2
python3 tools/experiments/root_recheck_compare.py \
  --output results/root-recheck-new.json
```

基準bin/matchは`851dc0f`の探索コードを使う。既存バイナリが違う場合は
基準版を別途準備し、`--baseline`で指定する。比較結果には両バイナリと
局面・評価データのSHA-256を記録する。新規プロセス、定跡OFF、
ShinON/support10/D10、Threads1、Hash512MBで比較する。

このランナーは6既知局面を深さ15と50万ノード上限で各版検索し、合法手を確認する。
10秒で停止を要求する。ノード上限は実際には超過するため、予算比較には
上限内に出力された最後のbound指定なしPVを用いる。実際のbestmoveや全探索量も
保存する。これは予算内の報告時点の比較であり、厳密な同一時間での対局ではない。

## 20局結果と打ち切り判断（2026-11-16）

`results/root-recheck-20games-20261116-085041.json` は全20局終了。
入力ハッシュ一致、エラー・再開なし。試作6勝11敗3未解決（先手4/5/1、後手2/6/2）。
未解決は全て同一局面4回、終端評価は双方0、連続王手の責任は未判定。
両版の平均応答は約2.004秒。先後両敗の開始局面4組、両勝1組。
小標本で弱体化を断定はしないが、採用を支持する結果ではない。
