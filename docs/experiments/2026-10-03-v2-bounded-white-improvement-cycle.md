# 後手v2の一区切りに向けた頻出局面の選別

## 目的と今回の範囲

ユーザーは標準定跡ありの技巧への勝ち越しを長期目標としつつ、後手定跡を一度確立して先手版へ移りたいと希望した。[Astraレビューの追記](2026-10-03-astra-white-book-independent-review.md)を受け、今回は改善サイクルを一回に絞る。

作業開始時HEADは `bf70542`。対象は既存v2の後手200局（先後交代２実行から50局ずつ、後手固定100局）。盤面・持駒・手番を照合して手順前後をまとめ、追加検証対象を３局面に絞った。最頻出局面は既存の完走解析を再利用し、残る２局面を新たに解析する。長い対局はユーザーがCodex外で実行する。

評価値は解析局面の手番側cp。新しい後手解析は新米長玉ON。異なる局面・深さ・限定範囲の値を差し引かない。以下の局群成績は実行・探索状態で選ばれた観測値であり、着手の因果効果ではない。

## 一局面だけを追加した試験版

`books/shin-yonenaga-white-book-v2-pawn25-experiment.txt` を作成した。元のv1に `books/shin-yonenaga-white-v2-pawn25-experiment.json` を重ねて生成し、v2の既存11局面はすべて保持、Bの△２五歩１局面だけを追加した（計12）。v1・v2・エンジンは変更していない。

Bを選んだ理由は、実戦に出た▲６五歩に対し同条件の深さ28で代案が首位になり、18手目なのでBookMaxPly20を変更せず一手の効果を比較できるため。30cp差は１回の探索結果であり、改善確定ではない。過去の到達率は14/200＝7%、直近後手固定では10/100＝10%と低く、全体成績への影響は小さい可能性がある。Aの△３四歩固定は到達率こそ高いが深さ間の順位逆転と△８三銀群の観測成績を踏まえて見送り、Cも今回追加しない。

検証済み：生成再現性、全11既存SFENの不変、全12局面の深さ１USI定跡ヒット、Bの手順前後での同一ヒット、Bで元v2が探索へ抜けること、OwnBook off時の探索、通常側で標準定跡が使われること。これらは読込・適用の検証であり強さの検証ではない。追加対局はまだ実行していない。

## 外部対局の比較計画とコマンド

今回の上限は50局×４実行、v2→試験版→試験版→v2の順、各版計100局。各実行を別プロセスで始め、深さ15・１スレッド・Hash512MB・後手固定・通常側標準定跡・BookMaxPly20・256手上限を揃える。同条件でも局間の置換表等は残り、同一初期局面からの対局を独立した100標本とみなした有意差の主張は避ける。順番の偏りを弱める設計であり、ランダム化や局面ごとのペア実験ではない。

プロジェクト直下で以下を実行する。１実行ずつ保存し、失敗した場合は後続へ進まない。既存の同名出力がある場合は別名にする。`caffeinate -i` はアイドルスリープを防ぐが、蓋を閉じても継続する保証はない。

```sh
run_white_cycle() {
  caffeinate -i python3 tools/paired_selfplay.py \
    --engine bin/release --book-file bin/book.bin \
    --shin-book on --shin-book-file "$1" --book-max-ply 20 \
    --shin-side white --games 50 --depth 15 --threads 1 --hash 512 \
    --max-plies 256 --timeout 300 --output "results/$2.json"
}
run_white_cycle books/shin-yonenaga-white-book-v2-experiment.txt v2-cycle-baseline-r1-white-depth15-50games &&
run_white_cycle books/shin-yonenaga-white-book-v2-pawn25-experiment.txt v2-cycle-pawn25-r1-white-depth15-50games &&
run_white_cycle books/shin-yonenaga-white-book-v2-pawn25-experiment.txt v2-cycle-pawn25-r2-white-depth15-50games &&
run_white_cycle books/shin-yonenaga-white-book-v2-experiment.txt v2-cycle-baseline-r2-white-depth15-50games
```

完了後はエラー・手番・勝敗・定跡ヒットを監査し、実行別と合算の得点率、B到達率、登録で実際に着手が変わった局数、B到達後の相手応手と中盤推移を確認する。今回の再集計ツールは既存200局専用なので、新しい50局実行の集計にはそのまま使わない。

試験版の改善が両反復で同方向に現れ、Bに到達した棋譜にも説明可能な改善があり、条件差や異常がなければ試験版を第一運用版の候補とする。ただし低到達率による少数例では強さの証明とは呼ばない。片方だけ良い、小差、ほぼ未到達、悪化ならv2を第一運用版として固定する。到達後だけの勝率も選択された局群なので、単独では採用根拠にしない。追加の無期限な試行は行わず先手版へ移る。

## 今回の区切り方

1. ３局面を超えて探索対象を広げず、小さい試験版を一つだけ比較候補にする。
2. 通常開始の後手固定対局を、同じ実行時バイナリ・先手標準定跡・深さ15等の条件で反復比較する。長い実行はユーザーがCodex外で行う。
3. 改善が再現するなら試験版を採用。差が曖昧、悪化、または登録が既存探索をほとんど変えない場合はv2を第一運用版として固定する。小差の統計的確定のために今回は無期限に対局を増やさない。
4. 第一運用版は「対標準定跡・先手四間飛車向け」と適用範囲を明記する。未対応戦型と残る中盤課題を保存し、先手版定跡へ移る。勝ち越し目標は継続課題として残し、移行の必須条件にはしない。

「運用版の確立」と「技巧への勝ち越しの実証」を区別する。この一回のサイクル終了後に別骨格・７筋形・未出現戦型へ研究範囲を広げるかは、先手版との優先順位を改めて決める。
