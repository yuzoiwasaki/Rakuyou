# 端歩待機・飛車先保留からの△７四歩：重点解析

## 結論

端歩で待って△８四歩を保留する構想は、**条件が整った局面での△７四歩～△７三銀という分岐として残す**。一方、今回の勝ち例の手順をそのまま主定跡へ固定する根拠には足りない。

- △７四歩直前の３局面は、深さ28でも首位または首位から１cp差に残った。第43局の負けを、この一手だけの問題とは扱わない。
- 先手には序盤の▲１六歩・▲５八金左、途中の▲２八玉など、保存棋譜とは異なる有力手がある。▲７七角を前提にした一本道にはしない。
- 第81局の△７二銀直前では、深さ28でも△３五歩・△５一玉が首位同点で、△７二銀は40cp下だった。魅力的な到達局面と、そこまでの手順の妥当性は分けて判断する。
- △７四歩後も、△７三銀・△７一玉・△２四歩の順序は固定しない。早い▲６五歩への△７三銀は支持されたが、△７二飛への自動的な移動は今回も採用しない。

v1・v2およびエンジン本体は変更していない。新しい対局は実施していない。

15種類の局面に対し、深さ24を15回、深さ28を４回、計19回の完了結果を保存した。全候補が要求深さに到達し、候補数・打ち切りなし・bound表示なし・首位PVとbestmoveの一致を確認した。

初期スクリーニングはサーバー再起動を挟んで再開した。生データの `errors` には `opponent_after_14_king48_15` の `Broken pipe` 記録が１件残っている。該当IDには深さ24の完了結果も保存されており、上記の確認を通過した。記録は削除せず保持する。通信エラーの詳細原因までは特定しておらず、「実行全体のエラー０」とは扱わない。他の６ファイルのエラー記録は０件。

探索状態を持ち越さないよう、最初のスクリーニングと親局面解析は既存の `Engine` を局面ごとに生成・終了した。追試には `tools/analyze_positions.py` の `--fresh-engine` を追加した。従来のプロセス再利用は既定値として維持する。起動時のZobristキーは依然として乱数化されるため、同条件の再実行で完全に同一の順位・評価となる保証はない。

入力局面は[既存の後手候補](positions/book/high-review-2026-10-02-shin.json)と[通常側候補](positions/book/high-review-2026-10-02-opponent.json)、および今回の `edge-wait-2026-10-02-*.json` を使用。新規５ファイルの入力114手は、実行ファイルの `legalmoves` と照合した。

## 1. 序盤から一本道にできるか

基準手順は以下。

```text
▲７六歩 △６二玉 ▲６八飛 △１四歩
```

この時点の先手応手は、深さ24で次の結果だった。

| 順位 | 先手の候補 | 通常側評価 |
|---:|---|---:|
| 1 | ▲１六歩 | +195 |
| 2 | ▲４八玉 | +178 |
| 3 | ▲６六歩 | +177 |
| 4 | ▲７八銀 | +177 |
| 5 | ▲７七角 | +176 |

▲４八玉の後、新米長玉側は△１五歩と△３四歩が−197で首位同点、△２四歩が−199だった。二度目の端歩は候補として支持されるが、必須手ではない。

一方、先手首位の▲１六歩を指された局面では、後手は△３四歩−140、△５一玉−141が上位。△８四歩・△５四歩は−175、△７二銀は−193で、△１五歩は上位５手に入らなかった。端を受けられた場合に、元の待機手順を機械的に続けない。

```text
▲７六歩 △６二玉 ▲６八飛 △１四歩
▲４八玉 △１五歩
```

この局面の先手候補は▲５八金左+209、▲６六歩+205、▲７八銀+205、▲３八玉+195、▲７七角+177。▲５八金左への後手応手は△８四歩−205が首位、△７二銀−210が次点、△３四歩・△２四歩が−215だった。

飛車先を保留する候補は残るが、相手の形によっては△８四歩が再び有力になる。「△８四歩を絶対に指さない」制約へは変えない。

## 2. △７四歩直前の勝ち例・負け例

標準定跡版の第81局・第63局は後手勝ち、第43局は後手負け。入力はそれぞれ △７四歩を指す直前の局面であり、３局面とも８三の歩は未着手、後手銀は７二、先手角は７七にいる。

| 元対局 | 深さ24の△７四歩 | 深さ24の次点 | 深さ28の△７四歩 | 深さ28の比較 |
|---|---|---|---|---|
| 第81局・勝ち | 1位 −155 | △２四歩 −179 | 1位 −142 | △２四歩 −178（36cp差） |
| 第63局・勝ち | 1位 −186 | △２五歩 −199 | 2位 −212 | △２五歩 −211（1cp差） |
| 第43局・負け | 1位 −171 | △５二金左 −267 | 1位 −208 | △３三角 −244（36cp差） |

第63局は深さによって△２五歩と△７四歩の順位が逆転した。１cp差は最善手の確定材料ではない。△２五歩の深さ28のPVにも、後で△７四歩～△７三銀が現れるため、構想自体を排除する結果ではない。

第81局の深さ28の首位PV冒頭は次の通り。

```text
△７四歩 ▲７八銀 △７三銀 ▲６五歩
△７一玉 ▲６七銀 △２四歩 ▲５六銀
△３二飛 ▲５五銀 △６二飛
```

玉・銀の順序は元対局と異なり、飛車も状況に応じて振り直している。このPVだけから、これらの後続手を全て定跡登録しない。

## 3. △７四歩までの入口を確認する

第81局の△７二銀直前は以下。

```text
▲７六歩 △６二玉 ▲６八飛 △１四歩
▲４八玉 △１五歩 ▲６六歩 △３四歩
▲３八玉
```

深さ24の後手候補は△５一玉−168、△３五歩−183、△２四歩−207、△７二銀−210、△３二銀−235だった。△７二銀は首位から42cp差。既存の玉配置補正が有効でも、退く手が上位に来る点は記録する。

同じ親局面の深さ28・MultiPV５は完了し、△３五歩・△５一玉が−167で首位同点、△７二銀が−207で３位、△３二銀−211、△２四歩−217となった。△７二銀は深さ24の42cp差から深さ28でも40cp差であり、今回の入口で銀の準備を定跡に固定する支持は弱い。

△３五歩と△５一玉のPVは手順前後で合流し、その後△６二銀・△５四歩などへ進んだ。「玉を６二から退かせない」という制約を後付けして、上位候補を排除しない。ただし、これも通常側への勝ち越しを示す結果ではない。

△７二銀を指した後の先手側を直接調べると、▲２八玉+212が首位、元対局の▲７七角+195が次点となった。17cp差であり、角上がりも有力だが最善手と断定しない。

先手が▲２八玉を選んだ局面で、新米長玉側は△２四歩−172、△３五歩−197、△７一玉−216を選び、△７四歩は上位５手外だった。▲７七角がない段階で、△７四歩を一律に登録する根拠は得られなかった。

この枝でも△２四歩のPVは、後に△２五歩・△５二金右・△８四歩などへ進む。角上がりがなければ従来の７筋構想だけに固執しない。

## 4. △７四歩後の強い応手に耐えられるか

第81局で△７四歩を指した直後の通常側解析では、▲７八銀+203が首位、▲６五歩+167、▲５八金左+165が続いた。元対局の▲７八銀はここでは支持された。

▲７八銀への後手直接解析は、△２四歩−150、△７一玉−152、△７三銀−161。上位３手のPVはいずれも後に△７三銀へ進むが、銀をすぐ上げる順に限定しない。

第63局で△７四歩を指した直後は、通常側の▲６五歩+234が首位。これに対する新米長玉側の直接解析は、△７三銀−173が首位、△２五歩−181が次点となった。第81局と違って玉はすでに７一におり、▲６五歩へ△７三銀で応じる具体的な枝が支持された。

いずれも限定局面での結果であり、一般的な▲６五歩への耐性や、この構想の勝率を測ったものではない。

## 次の流れ

1. 今回の端歩ルートは、条件付き分岐候補として保持する。△７四歩前の形は有望だが、親局面・別の先手応手を無視して一本道の定跡にしない。
2. 合意済みの第二候補、△５四歩骨格で△７二銀を早め、実際の▲６五歩に△７四歩を合わせる枝を検証する。まずその親局面から確認する。
3. 第一・第二候補で成立する枝が残れば小さい実験定跡へまとめ、v2を既存基準として対局比較する。正式採用判断はその後。
