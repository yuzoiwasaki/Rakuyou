# △７四歩～△７三銀案の標準定跡到達性

## 対象と条件

[従来の７筋構想の検討](2026-09-27-original-seventh-file-analysis.md)では、△７四歩まで入れば△７三銀が成立する枝があった。しかし、先手が早く▲７七角を選ぶ前提は実戦頻度が低かった。今回は通常Rakuyou（Gikou 2相当）が**標準定跡あり**で選びやすい手順から、△７四歩～△７三銀へ進めるかを調べた。ソースコミットは `b7cb3de`。エンジンは `bin/release`。

## 過去の自己対局との関係と判断

以前の後手自己対局で、序盤20手以内に△７四歩、その後24手以内に△７三銀へ進んだのは３局で２勝１敗。ただし３局とも今回の「△７二銀 ▲４八玉 △７四歩」とは**異なる前後手順**で、今回の入口の勝率を示さない。現在の第一版専用定跡100局では、この早い７筋構想は使っていない。

標準定跡の▲４八玉へすぐ△７四歩をぶつけると、後手側の全候補解析で深さ28でも８位・48点差となり、通常側は標準定跡を抜ける。▲３八玉を選ぶ枝では△７三銀が首位で形は作れるが、▲３八銀ではまず△５二玉が首位。△７四歩～△７三銀案は**到達した局面に応じた副枝**として残し、標準定跡相手の新たな主入口には採用しない。勝率への効果を主張するには、この入口を強制した別版の対照対局が必要だが、現時点では入口の評価差が大きく、優先度は低い。候補JSONとエンジン用定跡は変更しない。
