# 通常対局後の受け優先診断

実験ブランチ `experiment/defense-preference-within50` の393d1f2を使い、初期局面から通常対局を一局実施した。受け優先ルールは対局には適用せず、終了後に候補比較した。エンジン・評価関数・定跡の変更はない。

## 対局条件と結果

先手は通常設定、後手は新米長玉（support/contactとも10）。1手2秒、1スレッド、Hash512MB、定跡ON（新米長玉94局面、最大44手）、実験評価係数3種はすべて0。167手指した後、168手目に後手投了。ルールOFFのため、この勝敗から受け優先ルールの強さは評価できない。

入力のコピーとハッシュは `results/defense-preference-shadow-one/manifest.json` に保存。棋譜は `results/defense-preference-shadow-one.json`、ビューアは `results/defense-preference-shadow-one-review/game-full.html`。全指し手の合法性（打ち歩詰めを含む）を確認し、四回の同一局面なし。

## 比較方法

事前に後手32～100手目の探索手を対象とした。35局面を自動分類し、実戦手がattackで、defense候補がある7局面を比較。候補集合は実戦手と全自動defense候補のみ。全合法手からの最善手比較ではない。

各局面で新しいエンジンプロセスを使い、定跡OFF、同じ設定、MultiPV深さ18の一回の比較を行った。停止上限55秒、未完了・mate・bound評価は判定しない。今回7局面はすべて完了。中盤か・最初の仕掛けかは未自動化であり、人の確認が必要。診断は対局終了後なので対局の2秒探索と競合しない。

評価値はすべて後手視点。差は実戦手から受け候補を引いた値。

## 分類の検討点

実戦50手目の６四歩打は通常探索で選ばれた。侵入口を塞ぎ、同時に６五の相手飛車を狙うため、現在の分類ではmixedとなり比較対象外。受けながら反撃する手を除外してしまう可能性がある。38手目の１三角、42手目の６五桂などはattack判定だが、自動defense候補がなく比較していない。今回の0例はこの範囲・分類での結果であり、受けの選択肢が存在しないという意味ではない。結果を見て分類条件を変更することはせず、次の検討課題として残した。

## 再実行

生成物はignoredのresults内に保存。凍結した対局ランナーは `results/defense-preference-shadow-one/run.py`。同一時間制でも実行環境により棋譜は変わり得る。

```sh
python3 tools/analysis/shadow_defense_game.py \
  --game results/defense-preference-shadow-one.json \
  --engine results/defense-preference-shadow-one/runtime/bin/match \
  --output results/defense-preference-shadow-one/shadow.json
python3 -m unittest test.analysis.test_shadow_defense test.analysis.test_defense_preference
```

ルール単独の変更と再探索の順位変更を区別し、50/51点境界および未完了・mate除外をテストした。本実験は診断のみであり、採用や強さの改善は主張しない。
